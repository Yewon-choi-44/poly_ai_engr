## 1. Controller 코드 및 URL 매핑

### `0901WebTest` — `HelloController.java`

```java
@Controller
public class HelloController {

    // /hello → hello.jsp (JSP 스크립트릿으로 현재 시각 출력)
    @RequestMapping("/hello")
    public String hello() {
        return "hello";
    }

    // /about → about.jsp (정적 자기소개 정보 출력)
    @RequestMapping("/about")
    public String about() {
        return "about";
    }

    // /greet?name=홍길동 → greet.jsp (EL로 ${name} 출력)
    @RequestMapping("/greet")
    public String greet(@RequestParam String name, Model model) {
        model.addAttribute("name", name);
        return "greet";
    }

    // /today → today.jsp (Model로 title, author, comment 전달)
    @RequestMapping("/today")
    public String today(Model model) {
        model.addAttribute("title", "해리 포터와 마법사의 돌");
        model.addAttribute("author", "J.K. 롤링");
        model.addAttribute("comment", "상상력의 끝판왕, 한번 읽으면 멈출 수 없다!");
        return "today";
    }
}
```

**핵심 포인트**
- `@Controller` : 해당 클래스를 Spring MVC 컨트롤러로 등록
- `@RequestMapping("경로")` : 지정 URL 요청을 메서드에 매핑
- `@RequestParam` : URL 쿼리스트링 파라미터(`?name=...`)를 메서드 인자로 주입
- `Model` : Controller → View(JSP)로 데이터를 전달하는 인터페이스 (`addAttribute(key, value)`)

## 2. View Resolver 설정 (`application.properties`)

```properties
server.port=8090
spring.mvc.view.prefix=/WEB-INF/views/
spring.mvc.view.suffix=.jsp
```

- Controller가 `"hello"` 문자열을 반환하면 View Resolver가 `/WEB-INF/views/hello.jsp`로 해석한다.
- `tomcat-embed-jasper` 의존성이 없으면 JSP 렌더링이 되지 않으므로 `pom.xml`에 반드시 포함해야 한다.

### pom.xml 핵심 의존성

```xml
<!-- Spring MVC -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-webmvc</artifactId>
</dependency>
<!-- JSP 렌더링 엔진 -->
<dependency>
    <groupId>org.apache.tomcat.embed</groupId>
    <artifactId>tomcat-embed-jasper</artifactId>
    <scope>provided</scope>
</dependency>
```

## 3. JSP 뷰 파일 (`0901WebTest`)

### `hello.jsp` — JSP 스크립트릿으로 현재 시각 출력

```jsp
<%@ page contentType="text/html; charset=UTF-8" pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
  <head><title>JSP 테스트</title></head>
  <body>
    <h1>JSP 렌더링 성공</h1>
    <p>현재 시각: <%= new java.util.Date() %></p>
    <a href="/">메인으로</a>
  </body>
</html>
```

- `<%= ... %>` : JSP 스크립트릿 표현식, Java 코드 결과를 HTML에 직접 출력

### `greet.jsp` — EL로 Model 데이터 출력

```jsp
<h1>${name}님, 환영합니다.</h1>
<p>URL의 값이 Model을 거쳐 화면까지 전달되었습니다.</p>
```

- `${name}` : EL(Expression Language), Model에 담긴 값을 JSP에서 꺼내 출력

### `about.jsp` — 정적 HTML 자기소개 페이지

```jsp
<h1>자기소개</h1>
<p><b>이름</b> : 홍길동</p>
<p><b>좋아하는 것</b> : 게임, 아버지</p>
<p><b>만들고 싶은 것</b> : 나만의 도서관 서비스</p>
```

### `today.jsp` — Model로 전달된 복수 데이터 출력

```jsp
<h1>오늘의 추천 도서</h1>
<h2>${title}</h2>
<p>${author}</p>
<p>"${comment}"</p>
```

## 💡 핵심 문법 정리 표 (Key Takeaways)

| 개념 | 설명 | 예시 |
| :--- | :--- | :--- |
| `@Controller` | 클래스를 Spring MVC 컨트롤러로 등록 | `@Controller public class HelloController {}` |
| `@RequestMapping` | URL과 메서드를 연결 | `@RequestMapping("/hello")` |
| `@RequestParam` | URL 쿼리 파라미터를 메서드 인자로 주입 | `@RequestParam String name` |
| `Model` | Controller → View 데이터 전달 인터페이스 | `model.addAttribute("name", "홍길동")` |
| JSP 스크립트릿 | JSP 내 Java 코드 실행 | `<%= new java.util.Date() %>` |
| EL (Expression Language) | JSP에서 Model 데이터를 꺼내 출력 | `${name}`, `${title}` |
| View Resolver | Controller 반환 문자열 → JSP 경로 변환 | `"hello"` → `/WEB-INF/views/hello.jsp` |
| `spring.mvc.view.prefix/suffix` | `application.properties`에서 View Resolver 경로 설정 | `prefix=/WEB-INF/views/`, `suffix=.jsp` |
| `tomcat-embed-jasper` | WAR 패키징 없이 JSP 렌더링 가능하게 하는 의존성 | `<scope>provided</scope>` |
| WAR 패키징 | 외부 서블릿 컨테이너에 배포 가능한 형태 | `<packaging>war</packaging>` |
