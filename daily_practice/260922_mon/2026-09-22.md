## 3. DB 연동 코드 (JDBC 직접 사용)

### `DBconfig.java` — DataSource 빈 설정

```java
@Configuration
@PropertySource("classpath:db.properties")   // db.properties에서 값 주입
public class DBconfig {

    @Value("${db.driver}")   private String driver;
    @Value("${db.url}")      private String url;
    @Value("${db.username}") private String username;
    @Value("${db.password}") private String password;

    @Bean
    public DataSource dataSource() {
        DriverManagerDataSource ds = new DriverManagerDataSource();
        ds.setDriverClassName(driver);
        ds.setUrl(url);
        ds.setUsername(username);
        ds.setPassword(password);
        return ds;
    }

    @Bean
    public JdbcTemplate jdbcTemplate(DataSource dataSource) {
        return new JdbcTemplate(dataSource);
    }
}
```

> ⚠️ `db.properties`는 민감 정보(username, password)를 포함하므로 **`.gitignore`에 등록, 절대 커밋 금지**

### `BookDao.java` — JDBC 직접 사용 DAO

```java
@Repository
public class BookDao {
    private DataSource dataSource;

    @Autowired
    public BookDao(DataSource dataSource) {
        this.dataSource = dataSource;
    }

    // INSERT — 샘플 데이터 삽입 (테스트용)
    public void insertBook() {
        String sql = "INSERT INTO book(b_name, b_author, b_rental_able, b_reg_date, b_mod_date) "
                   + "VALUES(?, ?, ?, now(), now())";
        try (Connection conn = dataSource.getConnection();
             PreparedStatement pstmt = conn.prepareStatement(sql)) {
            pstmt.setString(1, "JDBC로 입력한 책");
            pstmt.setString(2, "홍길동");
            pstmt.setInt(3, 1);
            pstmt.executeUpdate();
        } catch (SQLException e) { e.printStackTrace(); }
    }

    // SELECT ALL — 전체 도서 목록 조회
    public List<BookVo> getAllBook() {
        String sql = "SELECT * FROM book ORDER BY b_no";
        List<BookVo> books = new ArrayList<>();
        try (Connection conn = dataSource.getConnection();
             PreparedStatement pstmt = conn.prepareStatement(sql);
             ResultSet rs = pstmt.executeQuery()) {
            while (rs.next()) {
                BookVo book = new BookVo();
                book.setB_no(rs.getInt("b_no"));
                book.setB_name(rs.getString("b_name"));
                book.setB_author(rs.getString("b_author"));
                // ... (나머지 필드 매핑)
                books.add(book);
            }
        } catch (SQLException e) { e.printStackTrace(); }
        return books;
    }
}
```

```java
    private String b_img;           // 이미지 경로
    private String b_reg_date;      // 등록일
    private String b_mod_date;      // 수정일
    // getter / setter 생략
}
```

### `BookRowMapper.java` — `RowMapper<BookVo>` 구현체

```java
public class BookRowMapper implements RowMapper<BookVo> {
    @Override
    public BookVo mapRow(ResultSet rs, int rowNum) throws SQLException {
        BookVo book = new BookVo();
        book.setB_no(rs.getInt("b_no"));
        book.setB_name(rs.getString("b_name"));
        // ... 나머지 필드
        return book;
    }
}
```

> `JdbcTemplate`을 사용할 때 `RowMapper`를 함께 넘기면 ResultSet → VO 매핑을 자동화할 수 있다.
> 현재 `BookDao`는 순수 JDBC(`PreparedStatement` 직접 사용)로 구현되어 있고, `BookRowMapper`는 추후 `JdbcTemplate` 방식으로 전환 시 사용 예정.

## 💡 핵심 문법 정리 표 (Key Takeaways)

| 개념 | 설명 | 예시 |
| :--- | :--- | :--- |
| `@Repository` | DAO 클래스를 Spring 빈으로 등록, 예외 변환 지원 | `@Repository public class BookDao {}` |
| `@Autowired` (생성자) | 생성자 주입 — 권장 방식, 테스트 용이 | `public BookDao(DataSource ds) {...}` |
| `@Configuration` | 빈 설정 클래스 선언 | `@Configuration public class DBconfig {}` |
| `@PropertySource` | 외부 `.properties` 파일을 스프링 환경에 로드 | `@PropertySource("classpath:db.properties")` |
| `@Value` | properties 값을 필드에 주입 | `@Value("${db.url}") private String url;` |
| `DataSource` | DB 커넥션 풀의 추상화 인터페이스 | `dataSource.getConnection()` |
| `DriverManagerDataSource` | 커넥션 풀 없는 단순 DataSource (개발용) | `new DriverManagerDataSource()` |
| `JdbcTemplate` | Spring JDBC 헬퍼 — SQL 실행, 예외 처리 자동화 | `jdbcTemplate.query(sql, rowMapper)` |
| `PreparedStatement` | SQL 파라미터 바인딩 (`?` 치환), SQL Injection 방지 | `pstmt.setString(1, "홍길동")` |
| `RowMapper<T>` | `ResultSet` 한 행을 Java 객체로 변환하는 인터페이스 | `implements RowMapper<BookVo>` |
| `@ResponseBody` | 반환값을 View 없이 HTTP 응답 body에 직접 쓰기 | `@ResponseBody public String dbTest()` |
| `redirect:경로` | Controller에서 리다이렉트 응답 반환 | `return "redirect:booklist"` |
| JSTL `c:forEach` | JSP에서 Collection 반복 출력 | `<c:forEach var="book" items="${books}">` |
| `<%@ include file="..." %>` | JSP 정적 include — 컴파일 시점에 파일 병합 | `<%@ include file="include/header.jsp" %>` |
| Bootstrap 5 Grid | `col-md-4` 기반 반응형 카드 레이아웃 | `<div class="col-md-4 mb-3">` |
