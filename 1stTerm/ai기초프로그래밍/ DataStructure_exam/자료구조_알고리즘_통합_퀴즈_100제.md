### 💡 1장 정답 및 해설

* **Q01. 정답: ③**
  * 해설: 자료(Data, D)를 처리(Processing, P)하여 정보(Information, I)를 산출하므로 $P(D) = I$가 맞습니다.
* **Q02. 정답: ②**
  * 해설: 트리와 그래프는 자료 간의 계층 또는 망 구조 관계를 나타내는 비선형 자료구조입니다. 리스트, 스택, 큐, 데크는 선형 구조입니다.
* **Q03. 정답: ①**
  * 해설: 자료의 크기 순은 Bit -> Byte -> Word -> Field(데이터 최소 단위) -> Record(자료 처리 단위) -> File -> Database 순입니다.
* **Q04. 정답: ②**
  * 해설: 1Byte는 8Bit이므로 $2^8 = 256$가지 상태를 표현할 수 있습니다.
* **Q05. 정답: ③**
  * 해설: 4비트(반 바이트)를 가리키는 정보 단위를 니블(Nibble)이라고 합니다.
* **Q06. 정답: ②**
  * 해설: 4바이트(32비트)는 Full Word(전단어), 2바이트는 Half Word(반단어)라고 합니다.
* **Q07. 정답: ③**
  * 해설: 특정한 의미를 가진 데이터의 최소 단위는 필드(Field) 또는 항목(Item)입니다.
* **Q08. 정답: ②**
  * 해설: 존 형식 정수 표현에서 양수의 부호는 16진수 `C`(2진수 `1100`), 음수의 부호는 `D`(2진수 `1101`)로 나타냅니다.
* **Q09. 정답: ①**
  * 해설: 543은 백의자리 5, 십의자리 4, 일의자리 3이므로 각각 존 비트(F)와 결합하여 `F5 F4 C3`이 됩니다. (마지막 3의 존 영역이 양수 부호 C로 변경됨)
* **Q10. 정답: ③**
  * 해설: 팩 형식은 1바이트에 수치 2자리를 채웁니다. 543은 5, 4, 3과 음수 부호 D가 합쳐져 최하위는 `3D`가 되고 그 앞은 `54`가 됩니다. 남는 상위 바이트는 0으로 채우므로 `00 00 54 3D`가 됩니다.
* **Q11. 정답: ②**
  * 해설: 2의 보수 방식에서 $n$비트의 표현 범위는 $-2^{n-1} \sim 2^{n-1}-1$입니다. 4비트일 경우 $-2^3 \sim 2^3-1$, 즉 $-8 \sim +7$입니다.
* **Q12. 정답: ③**
  * 해설: 부호와 절대치 및 1의 보수 방식은 `+0`과 `-0`이 따로 존재하여 총 2개의 0 표현이 존재하지만, 2의 보수 방식은 0의 표현이 오직 하나만 존재하여 연산 시 예외 처리가 필요 없어 연산 속도가 빠릅니다.
* **Q13. 정답: ②**
  * 해설: IEEE 754 단정도 표준 실수는 32비트(부호 1, 지수 8, 가수 23비트) 구조입니다. 배정도(Double Precision)는 64비트입니다.
* **Q14. 정답: ①**
  * 해설: 32비트 단정도 부동소수점의 지수 영역 바이어스 상수는 127입니다. (64비트 배정도는 1023)
* **Q15. 정답: ③**
  * 해설: $13.625$를 2진수로 변환하면 $1101.101_{(2)}$이 되며, 소숫점을 첫 1 뒤로 이동시켜 정규화하면 $1.101101_{(2)} \times 2^3$이 됩니다.
* **Q16. 정답: ③**
  * 해설: BCD 코드는 6비트로 구성되어 $2^6 = 64$개 문자를 나타냅니다.
* **Q17. 정답: ③**
  * 해설: 7비트 구성으로 128개 문자를 표현하며 통신 표준으로 사용되는 코드는 ASCII(아스키) 코드입니다.
* **Q18. 정답: ①**
  * 해설: 입력은 0개 이상(외부 입력이 없어도 됨)이어도 무방합니다. 단, 출력은 반드시 1개 이상 존재해야 합니다.
* **Q19. 정답: ③**
  * 해설: 빅오 성능 속도는 $\mathcal{O}(1) < \mathcal{O}(\log n) < \mathcal{O}(n) < \mathcal{O}(n \log n) < \mathcal{O}(n^2) < \mathcal{O}(2^n) < \mathcal{O}(n!)$ 이므로 보기 중에서는 $\mathcal{O}(\log n)$이 가장 빠릅니다.
* **Q20. 정답: ③**
  * 해설: 이중 루프를 도는 일반적인 버블 정렬의 최악 시간 복잡도는 $\mathcal{O}(n^2)$입니다.

### 💡 5장 정답 및 해설

* **Q81. 정답: ④**
  * 해설: 선형 검색은 데이터의 정렬 여부와 상관없이 맨 처음부터 무작위 탐색을 할 수 있습니다. 이진, 보간, 피보나치 검색은 필수적으로 데이터가 사전 정렬되어 있어야 합니다.
* **Q82. 정답: ③**
  * 해설: 선형 검색은 데이터를 일일이 순차 비교하므로 데이터 수에 정비례하는 $\mathcal{O}(n)$의 시간이 걸립니다.
* **Q83. 정답: ②**
  * 해설: 이진 검색의 최대 비교 횟수는 $\lfloor \log_2 n \rfloor + 1$입니다. $n=15$일 때 $\lfloor 3.9 \rfloor + 1 = 4$회입니다.
* **Q84. 정답: ②**
  * 해설: 찾고자 하는 값이 중앙값보다 작으면 중앙값 뒤의 영역은 볼 필요가 없으므로 상한선 포인터 `high`를 `mid - 1`로 줄입니다.
* **Q85. 정답: ①**
  * 해설: 전체 범위(0~14인덱스)의 중간 인덱스는 7(값 8)입니다. 14는 8보다 크므로 범위는 8~14인덱스로 좁혀지고 이들의 중간 인덱스는 11(값 12)입니다. 14는 12보다 크므로 범위는 12~14인덱스가 되고 이들의 중간 인덱스는 13(값 14)이 되어 정답을 찾습니다. 비교 순서는 8 -> 12 -> 14입니다.
* **Q86. 정답: ②**
  * 해설: 보간 검색의 예측 위치 산출 비례 공식은 $index = low + (high - low) \times \frac{key - A[low]}{A[high] - A[low]}$ 입니다.
* **Q87. 정답: ①**
  * 해설: 공식 대입 시 $index = 0 + 7 \times \frac{6-1}{8-1} = 7 \times \frac{5}{7} = 5$입니다. $A[5] = 6$이므로 정확히 단 1번만에 찾아냅니다.
* **Q88. 정답: ③**
  * 해설: 보간 검색은 데이터의 분포가 균등할 때는 효율적이나 치우쳐진 분포(예: 편중 데이터)에서는 범위를 반으로 좁히지 못해 최악의 경우 $\mathcal{O}(n)$ 성능이 납니다.
* **Q89. 정답: ②**
  * 해설: 사칙연산 중 덧셈과 뺄셈만을 사용하여 인덱스를 계산하며 피보나치 수열 분할을 이용하는 검색은 피보나치 검색입니다.
* **Q90. 정답: ③**

* **Q91. 정답: ②**

  * 해설: 이진 탐색 트리(BST)에 데이터를 정렬된 순서대로 삽입하면 한쪽으로만 뻗은 사향 이진 트리가 생성되며, 이 때 검색 시간은 선형 검색과 다름없는 $\mathcal{O}(n)$이 됩니다.
