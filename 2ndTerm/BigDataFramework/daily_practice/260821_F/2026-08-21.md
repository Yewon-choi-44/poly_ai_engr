## 3. 실습 2: 반응형 버튼 카운터 (Button Counter)

버튼 클릭 이벤트(`@click`)에 따라 반응형 변수(`count`, `count1`)의 값이 실시간으로 증감하도록 구현한 컴포넌트 실습입니다.

### 🧩 자식 컴포넌트: `ButtonCounter.vue`
```vue
<script lang="js" setup> // 자바스크립트 코드임을 명시 
import { ref } from 'vue' 

// ref() : 반응형 데이터로 만들어주는 함수
const count = ref(0) 
const count1 = ref(0)
</script>

<template>
  <!-- @click 이벤트와 {{ }} 텍스트 보간법 -->
  <button @click="count++">당신은 {{ count }} 번 클릭했습니다.</button>
  <div></div>
  <button @click="count1--">당신은 {{ count1 }} 번 클릭했습니다.</button>
</template>
```

### 🏠 부모 컴포넌트: `App.vue` (호출 및 렌더링)
```vue
<script setup>
import ButtonCounter from "./ButtonCounter.vue";
</script>

<template>
  <h1>아래에 자식 컴포넌트가 있습니다.</h1>
  <div></div>
  <ButtonCounter />  
</template>
```

```vue
<script lang="js" setup>
    import { ref } from 'vue';
    const rawHtml = '<span style="color:red">이것은 빨간색이어야 합니다.</span>';
</script>

</style>
```

## 5. 실습 4: 속성 바인딩 기본 (Attribute Binding - v-bind)

HTML 태그의 속성(Attribute)에 동적 데이터를 바인딩할 때 사용하는 `v-bind` 문법 실습입니다.

- `v-bind:id="dynamicId1"`: 전체 문법
- `:id="id"`: 축약형(Shorthand) 문법
- `v-bind:id`: 속성명과 변수명이 동일할 때 사용하는 동일 이름 축약형

### 🧩 자식 컴포넌트: `AttrBind1.vue` (`exam1/src/components/AttrBind1.vue`)
```vue
<template>
<div>
    <div v-bind:id="dynamicId1">{{ dynamicId1 }}</div>
    <div :id="id">{{ id }}</div>
    <div v-bind:id>{{ id }}</div>
    <div v-bind:id="id">{{ id }}</div>
</div>
</template>

<script lang="js" setup>
    import { ref } from 'vue';
    const dynamicId1 = "div1";
    const id = "div2";
</script>
```

### 🏠 부모 컴포넌트: `App.vue` (호출 및 렌더링)
```vue
<script lang="js" setup>
  import AttrBind1 from "./components/AttrBind1.vue";
</script>

<template>
  <AttrBind1 />
</template>
```

## 6. 실습 5: 불리언 속성 바인딩 (Boolean Attributes - :disabled)

버튼의 `disabled` 속성 등 존재 여부 자체가 참/거짓을 결정하는 불리언 속성의 바인딩 동작 방식을 테스트하는 실습입니다.

- **Falsy 값 (`false`, `null`, `undefined`, `0`)**: 속성이 포함되지 않아 버튼이 활성화 상태 유지
- **Truthy 값 (`true`, `""` 빈 문자열, `"true"` 문자열)**: 속성이 포함되어 버튼이 비활성화(`disabled`)됨

### 🧩 자식 컴포넌트: `AttrBind2.vue` (`exam1/src/components/AttrBind2.vue`)
```vue
<template>
    <div>
        <!-- False 계열 (버튼 활성화) -->
        <button :disabled="isButtonDisabledf1">False 버튼1 - {{ isButtonDisabledf1 }}</button>
        <button :disabled="isButtonDisabledf2">False 버튼2 - {{ isButtonDisabledf2 }}</button>
        <button :disabled="isButtonDisabledf3">False 버튼3 - {{ isButtonDisabledf3 }}</button>
        <button :disabled="isButtonDisabledf4">False 버튼4 - {{ isButtonDisabledf4 }}</button>
    </div>
    <div>
        <!-- True 계열 (버튼 비활성화) -->
        <button :disabled="isButtonDisabledt1">True 버튼1 - {{ isButtonDisabledt1 }}</button>
        <button :disabled="isButtonDisabledt2">True 버튼2 - {{ isButtonDisabledt2 }}</button>
        <button :disabled="isButtonDisabledt3">True 버튼3 - {{ isButtonDisabledt3 }}</button>
    </div>
</template>

<script lang="js" setup>
    import { ref } from 'vue'
    const isButtonDisabledf1 = ref(false)
    const isButtonDisabledf2 = ref(null)
    const isButtonDisabledf3 = ref(undefined)
    const isButtonDisabledf4 = ref(0)
    
    const isButtonDisabledt1 = ref(true)
    const isButtonDisabledt2 = ref("")
    const isButtonDisabledt3 = ref("true")
</script>

<style scoped>
    div {
        display: flex;
        flex-direction: column;
    }
    button {
        margin: 5px;
    }
</style>
```

### 🏠 부모 컴포넌트: `App.vue` (호출 및 렌더링)
```vue
<script lang="js" setup>
  import AttrBind2 from "./components/AttrBind2.vue";
</script>

<template>
  <AttrBind2 />
</template>
```

## 8. 실습 7: 이벤트 핸들러를 통한 반응형 이미지 변경

버튼 클릭 시 화살표 함수(`changeimg`)를 호출하여 이미지 URL 상태(`imagePath`)를 동적으로 교체하는 실습입니다.

> 💡 **동작 팁**: 스크립트 내에서 `.value`를 통해 값을 갱신하여 템플릿에 실시간 반영하려면 `const imagePath = ref("...")` 형태로 반응형 선언이 필요합니다.

### 🧩 자식 컴포넌트: `AttrBind3_2.vue` (`exam1/src/components/AttrBind3_2.vue`)
```vue
<template>
    <p>이미지 URL {{ imagePath }}</p>
    <br>
    <img :src="imagePath"/>
    <!-- 클릭 시 changeimg 함수 실행 -->
    <button @click="changeimg">변경</button>
</template>

<script lang="js" setup>
    import { ref } from 'vue';
    // 반응형 변수로 선언 시 UI 자동 갱신 가능
    const imagePath = ref("https://sponsors.vuejs.org/images/chrome_frameworks_fund.png");

    const changeimg = () => {
        imagePath.value = "https://aka-dolfood.moall.shop/data/goods/sm7396/small/thum4/KakaoTalk_20260804_165859549.png";
    }
</script>

<style>
</style>
```

### 🏠 부모 컴포넌트: `App.vue` (호출 및 렌더링)
```vue
<script lang="js" setup>
  import AttrBind3_2 from "./components/AttrBind3_2.vue";
</script>

<template>
  <AttrBind3_2 />
</template>
```

## 9. 실습 8: 동적 인자 바인딩 (Dynamic Arguments - :[attributeName])

```vue
<script setup>
    import { ref } from 'vue';
```

## 10. 실습 9: 다중 속성 객체 일괄 바인딩 (v-bind with Object)

인자(속성명) 없이 `v-bind`에 객체를 직접 전달하여, 객체 내부의 키-값 쌍들을 요소의 여러 HTML 속성으로 한 번에 바인딩하는 실습입니다.

- `v-bind="objectOfAttrs"`: `{ id: 'container', class: 'wrapper' }` 객체가 `<div id="container" class="wrapper">`로 자동 분해되어 적용됩니다.

### 🧩 자식 컴포넌트: `DynaAttr2.vue` (`exam1/src/components/DynaAttr2.vue`)

```vue
<template>

     <div v-bind="objectOfAttrs">div</div>
   </div>
</template>

<script lang="js" setup>
    import { ref } from 'vue';
    const objectOfAttrs = {
        id: 'container',
        class: 'wrapper'
    }    
</script>

<style>
</style>
```

### 🏠 부모 컴포넌트: `App.vue` (호출 및 렌더링)

## 13. 실습 12: 템플릿 내 자바스크립트 표현식 (JavaScript Expressions)

Vue 템플릿 내의 Mustache(`{{ }}`) 및 디렉티브 바인딩 속성 내에서 단일 자바스크립트 표현식을 자유롭게 평가하는 실습입니다.

- **산술 연산**: `{{ number + 1 }}`
- **삼항 연산자**: `{{ ok ? '예' : '아니오' }}`
- **메서드 체이닝**: `{{ message.split('').reverse().join('') }}`
- **템플릿 리터럴 속성 바인딩**: `:id="`list-${id}`"`

### 🧩 자식 컴포넌트: `JSExpr.vue` (`exam1/src/components/JSExpr.vue`)
```vue

    <div>{{ number + 1 }}</div><br>
    <div>{{ ok ? '예' : '아니오' }}</div><br>
    <div>{{ message.split('').reverse().join('') }}</div><br>
    <div :id="`list-${id}`"> div{{ `list-${id}` }}</div><br>
</template>

<script lang="js" setup>
    import { ref } from 'vue';
    
    const number = 1;
    const ok = true;
    const message = '안녕하세요';
    const id = 7;
</script>

<style>
</style>
```

### 🏠 부모 컴포넌트: `App.vue` (호출 및 렌더링)

## 14. 실습 13: 조건부 렌더링 기본 (v-if vs v-show)

조건에 따라 요소를 렌더링하는 `v-if`와 `v-show` 디렉티브의 동작 차이를 실습합니다.

- `v-if`: 조건이 거짓일 때 DOM 트리에서 요소가 완전히 제거됨 (초기 렌더링 비용 낮음, 전환 비용 높음)
- `v-show`: 조건과 무관하게 DOM에 항상 존재하며 CSS `display: none` 속성으로만 토글됨 (초기 비용 높음, 전환 비용 낮음)

### 🧩 자식 컴포넌트: `CondRender.vue` (`exam1/src/components/CondRender.vue`)
```vue
<template>
    <button @click="toggle">전환</button>
    <br>
    <h1 v-if="awesome">v-if Vue is awesome!</h1>
    <br>
    <h1 v-show="!awesome">v-show Vue is awesome!</h1>
</template>

<script setup>
    import { ref } from 'vue';

    const awesome = ref(true);
    function toggle() {
        awesome.value = !awesome.value;
    }
</script>

<style>
</style>
```

### 🏠 부모 컴포넌트: `App.vue` (호출 및 렌더링)
```vue
<script lang="js" setup>
  import CondRender from "./components/CondRender.vue";
</script>

<template>
  <CondRender />
</template>
```

## 15. 실습 14: 다중 조건부 렌더링 (v-if, v-else-if, v-else)

`v-if`, `v-else-if`, `v-else`를 사용하여 다중 분기 조건에 따라 적절한 블록을 렌더링하는 실습입니다.

### 🧩 자식 컴포넌트: `CondRender2.vue` (`exam1/src/components/CondRender2.vue`)
```vue
<template>
    <button @click="toggle">전환</button><br>
    <h1 v-if="type === 'A'">A!</h1>
    <h1 v-else-if="type === 'B'">B!</h1>
    <h1 v-else-if="type === 'C'">C!</h1>
    <h1 v-else>A/B/C 아님</h1>
</template>

<script setup>
    import { ref } from 'vue';
    const type = ref('A');
    const toggle = () => {
        switch(type.value) {
            case 'A': type.value = 'B'; break;
            case 'B': type.value = 'C'; break;
            case 'C': type.value = 'D'; break;
            default: type.value = 'A'; break;
        }
    }
</script>
```

### 🏠 부모 컴포넌트: `App.vue` (호출 및 렌더링)
```vue
<script lang="js" setup>
  import CondRender2 from "./components/CondRender2.vue";
</script>

<template>
  <CondRender2 />
</template>
```

```vue
</style>
```

## 17. 💡 핵심 문법 정리 (Key Takeaways)

| 문법 / 디렉티브 | 설명 | 예시 |
|---|---|---|
| `<script setup>` | Vue 3 Composition API의 간결한 SFC 작성 구문 | `<script setup>` |
| `ref(초기값)` | 원시값을 반응형 객체로 래핑하여 상태 변화 감지 및 UI 자동 갱신 | `const count = ref(0)` |
| `{{ expression }}` | 텍스트 보간법 및 단일 자바스크립트 표현식 평가 출력 | `<span>{{ num + 1 }}</span>`, `{{ ok ? 'Y' : 'N' }}` |
| `v-html="htmlString"` | 문자열을 실제 HTML DOM으로 파싱하여 렌더링 (XSS 보안 주의) | `<span v-html="rawHtml">` |
| `v-bind:attr="val"` 또는 `:attr="val"` | HTML 속성에 동적 자바스크립트 표현식/변수 바인딩 | `<div :id="id">`, `<img :src="path">` |
| `:attr` (동일 이름 축약) | 속성명과 변수명이 같을 때 단축 표기 (Vue 3.4+) | `<div :id>` 또는 `<div v-bind:id>` |
| `:[dynamicAttr]="val"` | 동적 인자 바인딩. 대괄호 속 변수명이 HTML 속성명이 됨 | `<a :[attrName]="url">` |
| `v-bind="object"` | 다중 속성 객체 바인딩. 객체의 모든 프로퍼티를 HTML 속성으로 일괄 적용 | `<div v-bind="obj">` |
| `:disabled="condition"` | 불리언 속성 바인딩. Truthy 값일 때 속성 적용, Falsy일 때 속성 제거 | `<button :disabled="isPending">` |
| `v-if` / `v-else-if` / `v-else` | 조건부 렌더링. 조건이 거짓이면 실제 DOM에서 제거됨 | `<h1 v-if="type === 'A'">` |
| `v-show="condition"` | 조건부 표시. DOM에 유지되며 CSS `display: none`으로 토글 | `<h1 v-show="isVisible">` |
| `@click="handler"` | 클릭 이벤트 핸들러 연결 (인라인 로직 또는 함수 호출) | `<button @click="increment">` |
| `.value` | `<script setup>` 내에서 `ref` 변수의 값을 읽거나 수정할 때 접근 | `count.value++` |
| 컴포넌트 등록 | `<script setup>` 내에서 `import` 시 템플릿 태그로 즉시 사용 가능 | `import Child from './Child.vue'` |
