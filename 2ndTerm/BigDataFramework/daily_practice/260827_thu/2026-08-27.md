### 실습 1: ref() 기본 및 setup() 함수 (RefExam.vue)
- **핵심 원리**: Options API의 `setup()` 함수 내에서 `ref()`를 선언하고 객체 형태로 return하여 템플릿에 바인딩합니다. 자바스크립트에서는 `.value`로 접근하지만, 템플릿에서는 최상위 ref에 대해 자동으로 언래핑됩니다.

```vue
<!-- exam1/src/components/RefExam.vue -->
<template>
  <span style="color:red"><h1>아래에 자식 컴포넌트가 있습니다..</h1></span>
  <div>
    <button @click="increment">
      {{ count }}
    </button>
    {{ count1 }}
  </div>
  <div>
    {{ count2 }}
  </div>
</template>

<script>
import { ref } from 'vue'

export default {
  setup () {
    const count = ref(0)
    let count2 = 5
    const increment = () => {
      count.value++
      count2++ // 일반 변수는 UI에 반응형으로 갱신되지 않음
    }
    return {
      count,
      count1: count, // 동일한 ref 참조
      count2: count2,
      increment
    }
  }
}
</script>
```

### 실습 4: reactive() 재할당 제약 및 프록시 동일성 (ReactiveReDef.vue)
- **핵심 원리**:
  1. `reactive(raw) === raw`는 `false` (반환값은 프록시 객체)
  2. 동일한 원본 객체에 대해 `reactive()`를 다시 호출하면 기존 프록시를 반환 (`true`)
  3. 이미 프록시인 객체에 `reactive()`를 호출해도 동일한 프록시 반환 (`true`)
  4. `ref(raw)`는 새 RefImpl 객체를 생성하므로 이전과 다름 (`false`), 단 `ref(state) === state`는 이미 ref인 경우 동일 반환 (`true`)

```vue
<!-- exam1/src/components/ReactiveReDef.vue -->
<template>
  <span style="color:red"><h1>아래에 자식 컴포넌트가 있습니다...</h1></span>
  <div>
    <h1> {{ raw }}</h1>
    <h1> {{ proxy }}</h1>
    <h1> {{ state }}</h1>
  </div>
</template>

<script setup>
import { reactive, ref } from 'vue'

const raw = { 'vue': 'good' }
const state = ref(raw)
const proxy = reactive(raw)

console.log(proxy == raw)             // false (프록시와 원본은 다름)
console.log(reactive(raw) === proxy)   // true  (원본 객체에 대해 동일 프록시 반환)
console.log(reactive(proxy) === proxy) // true  (프록시를 reactive로 감싸도 동일)
console.log(ref(raw) === state)        // false (매번 새 ref 인스턴스 생성)
console.log(ref(state) == state)       // true  (ref 인스턴스를 ref로 감싸면 자기 자신 반환)
</script>
```

### 실습 5: 중첩 객체 깊은 반응성 vs shallowRef (DeepReactivity.vue)
- **핵심 원리**:
  - `ref()`: 기본적으로 **깊은 반응성(Deep Reactivity)**을 제공하여 중첩 객체(`obj.nested.count`)나 배열 요소(`arr.push()`) 변경 시에도 감지하고 렌더링을 유발합니다.
  - `shallowRef()`: 루트 수준(`.value`)의 교체만 추적하며, 내부 중첩 프로퍼티 변경은 추적하지 않습니다. 변경을 반영하려면 객체 전체를 새로 복사하여 할당(`...`)해야 합니다.

```vue
<!-- exam1/src/components/DeepReactivity.vue -->
<template>
  <span style="color:red"><h1>아래에 자식 컴포넌트가 있습니다...</h1></span>
  <div>
    <button @click="mutateDeeply">Deep Trigger</button>
    <div>{{ obj.a }}</div>
    <div>{{ obj.nested.count }}</div>
    <div>{{ obj.arr }}</div>
  </div>

  <div>
    <button @click="mutateShallowly">Shallow Trigger (동작 안 함)</button>
    <button @click="mutateShallowlyFixed">Shallow Fixed Trigger (동작 함)</button>
    <div>{{ shallowObj.a }}</div>
    <div>{{ shallowObj.nested.count }}</div>
    <div>{{ shallowObj.arr }}</div>
  </div>
</template>

<script setup>
import { ref, shallowRef } from 'vue'

const obj = ref({
  a: 0,
  nested: { count: 0 },
  arr: ['foo', 'bar']
})

const shallowObj = shallowRef({
  a: 0,
  nested: { count: 0 },
  arr: ['foo', 'bar']
})

// 깊은 반응성: 내부 속성 변경 감지
const mutateDeeply = () => {
  obj.value.a++
  obj.value.nested.count++
  obj.value.arr.push('baz')
}

// 얕은 반응성: 내부 속성 변경 감지 불가 (렌더링 미반영)
const mutateShallowly = () => {
  shallowObj.value.a++
  shallowObj.value.nested.count++
  shallowObj.value.arr.push('baz')
}

// 얕은 반응성 해결책: 객체 전체를 새 참조로 교체
const mutateShallowlyFixed = () => {
  shallowObj.value = {
    ...shallowObj.value,
    a: shallowObj.value.a + 1,
    nested: { ...shallowObj.value.nested, count: shallowObj.value.nested.count + 1 },
    arr: [...shallowObj.value.arr, 'baz']
  }
}
</script>
```

### 실습 7: ref vs reactive 구조분해 및 인자 전달 (ReactiveDiff2.vue)
- **핵심 원리**:
  - `state1.count`처럼 원시값을 함수의 인자로 전달하면 값 복사(Call by Value)가 일어나 원본의 반응성 연결이 끊어집니다.
  - 객체 자체(`state1`) 또는 ref 인스턴스(`state2`)를 넘겨야 함수 내부에서 프로퍼티를 변경했을 때 반응성이 유지됩니다.

```vue
<!-- exam1/src/components/ReactiveDiff2.vue -->
<template>
  <div>
    <h1> reactive: {{ state1 }} </h1>
    <h1> ref: {{ state2 }} </h1>
    <button @click="test1">원시값 인자 전달 (반응성 X)</button>
    <button @click="test2">객체/Ref 인자 전달 (반응성 O)</button>
  </div>
</template>

<script setup>
import { ref, reactive } from 'vue'

const state1 = reactive({ count: 0 })
const state2 = ref({ count: 0 })

const callSomeFn1 = (c) => { c += 15 } // 원시값 복사이므로 원본에 영향 없음
const callSomeFn2 = (c) => { c.count += 15 } // reactive 객체 참조를 받아 수정
const callSomeFn3 = (c) => { c.value.count += 15 } // ref 객체 참조를 받아 수정

const test1 = () => {
  callSomeFn1(state1.count)
  callSomeFn1(state2.value.count)
}

const test2 = () => {
  callSomeFn2(state1)
  callSomeFn3(state2)
}
</script>
```

### 실습 8: ref 내부 Getter/Setter 동작 원리 (PseudoRef.vue)
- **핵심 원리**: Vue의 `ref`는 내부적으로 `get value()`(의존성 수집 track)와 `set value()`(의존성 트리거 trigger)를 구현한 객체 구조입니다.

```vue
<!-- exam1/src/components/PseudoRef.vue -->
<template>
  <span style="color:red"><h1>아래에 자식 컴포넌트가 있습니다...</h1></span>
  <button @click="count.value++">
    {{ count.value }}
  </button>
</template>

<script setup>
import { getCurrentInstance } from 'vue'

const instant = getCurrentInstance()

// Pseudo-ref 구현체 (동작 메커니즘 이해용)
const count = {
  _value: 0,
  get value() {
    console.log('get', this._value) // track()
    return this._value
  },
  set value(newValue) {
    this._value = newValue
    console.log('set', this._value)
    if (instant) {
      instant.proxy.$forceUpdate() // trigger()
    }
  }
}
</script>
```

### 실습 9: DOM 비동기 업데이트 큐와 nextTick() (NextTick.vue)
- **핵심 원리**: Vue는 반응형 상태가 변경될 때 즉시 DOM을 동기식으로 갱신하지 않고, 이벤트 루프의 "다음 틱(tick)"까지 대기 후 일괄 처리(Batching)합니다. DOM이 실제로 렌더링된 직후의 요소에 접근하려면 `await nextTick()`을 사용해야 합니다.

```vue
<!-- exam1/src/components/NextTick.vue -->
<template>
  <span style="color:red"><h1>아래에 자식 컴포넌트가 있습니다...</h1></span>
  <h1 class="counter" ref="h1Ref">{{ count1 }}</h1>
  <button @click="increment">increment 루프</button>
  <button @click="withoutTick">nextTick 없이 확인</button>
  <button @click="withTick">nextTick 있이 확인</button>
</template>

<script setup>
import { ref, nextTick } from 'vue'

const count1 = ref(0)
const h1Ref = ref(null)
const sleep = (ms) => new Promise(r => setTimeout(r, ms))

const withoutTick = () => {
  count1.value += 1
  // DOM 갱신 전이므로 textContent는 이전 값 출력
  console.log('DOM 즉시 확인:', h1Ref.value.textContent)
}

const withTick = async () => {
  count1.value += 1
  await nextTick()
  // nextTick 대기 후이므로 DOM에 반영된 최신 값 출력
  console.log('DOM nextTick 후 확인:', h1Ref.value.textContent)
}

const increment = async () => {
  for (let i = 0; i < 5; i++) {
    count1.value += 1
    await nextTick()
    await sleep(400)
  }
}
</script>

<style scoped>
.counter {
  transition: all 0.3s ease;
  font-size: 3rem;
}
</style>
```

### 실습 11: Computed 캐싱 메커니즘 vs Methods 호출 (CachedPropFunc.vue)
- **접속 URL**: `/cached-prop-func`
- **핵심 원리**: 
  - **Computed**: 의존성 대상 반응형 상태가 변경되지 않는 한, 템플릿에서 여러 번 호출되어도 **캐시된 결과**를 즉시 반환 (`console.log('computed')`가 1회만 실행).
  - **Method**: 템플릿에서 렌더링될 때마다 매번 함수를 다시 실행 (`console.log('calculate')`가 호출 횟수만큼 반복 실행).

```vue
<!-- exam2/src/pages/CachedPropFunc.vue -->
<script setup>
import { reactive, computed } from 'vue'

const author = reactive({
  name: 'John Doe',
  books: [
    'Vue 2 - Advanced Guide',
    'Vue 3 - Basic Guide',
    'Vue 4 - The Mystery'
  ]
})

const publishedBooksMessage = computed(() => {
  console.log('computed') // 의존성 불변 시 1회만 실행
  return author.books.length > 0 ? 'Yes' : 'No'
})

const calculateBooksMessage = () => {
  console.log('calculate') // 템플릿에서 3번 호출 시 3번 모두 실행
  return author.books.length > 0 ? 'Yes' : 'No'
}
</script>

<template>
  <p>computed property (캐싱됨)</p>
  <span>#1 {{ publishedBooksMessage }}</span>
  <span>#2 {{ publishedBooksMessage }}</span>
  <span>#3 {{ publishedBooksMessage }}</span>

  <p>method (매번 실행됨)</p>
  <span>#1 {{ calculateBooksMessage() }}</span>
  <span>#2 {{ calculateBooksMessage() }}</span>
  <span>#3 {{ calculateBooksMessage() }}</span>
</template>
```

### 실습 12: Writable Computed - Getter & Setter (WritableComputed.vue)
- **접속 URL**: `/writable-computed`
- **핵심 원리**: `computed({ get(), set(val) })` 구문을 통해 값을 읽을 때와 새로운 값을 할당할 때의 동작을 분기하여 양방향 계산된 속성을 정의합니다.

```vue
<!-- exam2/src/pages/WritableComputed.vue -->
<script setup>
import { ref, computed } from 'vue'

const firstName = ref('John')
const lastName = ref('Doe')

const fullName = computed({
  get() {
    return firstName.value + ' ' + lastName.value
  },
  set(newValue) {
    // 구조 분해 할당을 통해 성과 이름을 분리하여 각각의 ref에 반영
    [firstName.value, lastName.value] = newValue.split(' ')
  }
})
</script>

<template>
  <v-app>
    <v-main class="pa-4">
      <v-text-field
        label="FullName"
        @update:modelValue="newValue => fullName = newValue"
      ></v-text-field>
      <v-list>
        <v-list-item>
          <v-list-item-title>FullName: {{ fullName }}</v-list-item-title>
          <v-list-item-subtitle>
            FirstName: {{ firstName }} / LastName: {{ lastName }}
          </v-list-item-subtitle>
        </v-list-item>
      </v-list>
    </v-main>
  </v-app>
</template>
```

### 실습 15: 동적 클래스 바인딩 - 객체 구문 (ClassBind.vue)
- **접속 URL**: `/class-bind`
- **핵심 원리**: `:class="{ className: booleanValue }"` 또는 `:class="reactiveObject"` 구문을 통해 조건부로 CSS 클래스를 토글합니다.

```vue
<!-- exam2/src/pages/ClassBind.vue -->
<script setup>
import { ref, reactive } from 'vue'

const isActive = ref(true)
const hasError = ref(false)

const classObject = reactive({
  active: true,
  'text-danger': false
})

const toggleActive = () => {
  isActive.value = !isActive.value
  classObject.active = !classObject.active
}

const toggleError = () => {
  hasError.value = !hasError.value
  classObject['text-danger'] = !classObject['text-danger']
}
</script>

<template>
  <div class="static ma-2" :class="{ active: isActive, 'text-danger': hasError }">
    클래스 바인딩 예제
  </div>

  <div class="static ma-2" :class="classObject">
    객체 클래스 바인딩 예제
  </div>

  <v-btn @click="toggleActive">Active btn</v-btn>
  <v-btn @click="toggleError">Error btn</v-btn>
</template>

<style>
.active { background-color: #ffa600; }
.text-danger { color: #720c0c; }
</style>
```

### 실습 18: 동적 인라인 스타일 바인딩 (StyleBind.vue)
- **접속 URL**: `/style-bind`
- **핵심 원리**: `:style`에 객체(`{ color: activeColor, fontSize: fontSize + 'px' }`) 또는 스타일 객체를 전달하여 인라인 CSS를 동적으로 바인딩합니다.

```vue
<!-- exam2/src/pages/StyleBind.vue -->
<script setup>
import { ref, reactive } from 'vue'

const activeColor = ref('red')
const fontSize = ref(30)

const styleObject = reactive({
  color: 'red',
  fontSize: '13px'
})

const toggle_l = () => {
  fontSize.value++
  styleObject.fontSize = parseInt(styleObject.fontSize.trimEnd('px')) + 1 + 'px'
}

const toggle_s = () => {
  fontSize.value--
  styleObject.fontSize = parseInt(styleObject.fontSize.trimEnd('px')) + (-1) + 'px'
}
</script>

<template>
  <div class="ma-2" :style="{ color: activeColor, fontSize: fontSize + 'px'}">바인딩#1</div>
  <div class="ma-2" :style="{ 'font-size': fontSize + 'px'}">바인딩#2</div>
  <div class="ma-2" :style="styleObject">바인딩#3</div>
  <v-btn @click="toggle_l">글자 크게</v-btn>
  <v-btn @click="toggle_s">글자 작게</v-btn>
</template>
```

## 💡 3️⃣ 핵심 문법 및 개념 정리 표 (Key Takeaways)

| 구분 | 개념 / API | 설명 및 핵심 용법 | 주의사항 / 팁 |
|------|-----------|------------------|-------------|
| **반응성** | `ref()` | 원시값 및 객체를 모두 감쌀 수 있는 반응형 래퍼 (`.value`로 접근) | 템플릿에서는 `.value` 자동 언래핑, `<script setup>`에서는 `.value` 명시 |
| **반응성** | `reactive()` | 객체 전용 반응형 Proxy 객체 생성 | 원시값 불가, 구조분해할당 시 반응성 끊김, 객체 통째 재할당 불가 |
| **반응성** | `shallowRef()` | 루트 `.value` 변경만 감지하는 얕은 반응성 | 성능 최적화용. 내부 속성 수정 시 새 객체로 복사 할당 필요 |
| **비동기 DOM** | `nextTick()` | DOM 일괄 갱신 큐가 처리된 직후 Promise 반환 | 상태 변경 직후 DOM 크기/텍스트 측정 시 `await nextTick()` 필수 |
| **계산된 속성** | `computed()` | 의존성 반응형 데이터 기반 캐시된(Cached) 읽기 전용 ref 반환 | 의존 상태 변경 시에만 재계산되어 Method 호출 대비 성능 우수 |
| **계산된 속성** | `Writable computed` | `get()`과 `set(val)`을 모두 정의하여 양방향 읽기/쓰기 가능 | `v-model`과 연동하여 복합 상태 분해/조합에 유용 |
| **클래스 바인딩** | `:class="{ active: isActive }"` | 불리언 조건에 따라 특정 클래스를 동적으로 ON/OFF | `:class="[classA, classB]"` 배열 구문과 혼합 사용 가능 |
| **속성 상속** | `$attrs.class` | 다중 루트(Multi-root) 컴포넌트에서 부모의 클래스를 특정 엘리먼트에 상속 | 단일 루트 컴포넌트는 최상위 태그에 자동 병합됨 |
| **스타일 바인딩** | `:style="{ color, fontSize }"` | camelCase 또는 kebab-case 인라인 CSS 속성 동적 바인딩 | 단위(`px` 등)를 문자열에 반드시 포함할 것 |
| **폼 바인딩** | `v-model` (단일/다중) | input(text), textarea, checkbox, radio, select 양방향 데이터 동기화 | 다중 checkbox는 배열(`[]`), radio는 단일값으로 수집 |
| **UI 컴포넌트** | `<v-text-field>` | Vuetify 3의 텍스트 입력창 컴포넌트 | `prepend-inner-icon`, `clearable`, `variant="underlined"` 등 활용 |
