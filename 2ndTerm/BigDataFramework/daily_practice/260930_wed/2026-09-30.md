### 2.1 `FlexAlignSelf.vue` — align-self
```vue
<template>
    <div class="meal-css-tester-container ma-4 d-flex align-center" :style="{ height: '15rem'}" >
        <div class="meal-css-tester-item d-flex" :style="{ alignSelf: alignSelf1 }">aaaaaa</div>
        <div class="meal-css-tester-item d-flex" :style="{ alignSelf: alignSelf2 }">bbbbbbbbbbb</div>
        <div class="meal-css-tester-item d-flex" :style="{ alignSelf: alignSelf3 }">Gggg</div>
    </div>

    <div class="ma-4">1. align-self1: {{  alignSelf1  }}</div>
    <v-btn-toggle variant="outlined" divided class="ma-4" v-model="alignSelf1">
        <template v-for="option in options">
            <v-btn :text="option" :value="option"></v-btn>
        </template>
    </v-btn-toggle>

    <div class="ma-4">2. align-self2: {{ alignSelf2 }}</div>
     <v-btn-toggle variant="outlined" divided class="ma-4" v-model="alignSelf2">
        <template v-for="option in options">
            <v-btn :text="option" :value="option"></v-btn>
        </template>
    </v-btn-toggle>

    <div class="ma-4">2. align-self3: {{ alignSelf3 }}</div>
     <v-btn-toggle variant="outlined" divided class="ma-4" v-model="alignSelf3">
        <template v-for="option in options">
            <v-btn :text="option" :value="option"></v-btn>
        </template>
    </v-btn-toggle>
</template>

<script setup>
    import { ref } from 'vue'

    const alignSelf1 = ref("auto")
    const alignSelf2 = ref("auto")
    const alignSelf3 = ref("auto")
    const options = ref([
        "auto",
        "stretch",
        "flex-start",
        "flex-end",
        "center",
        "baseline"
    ])
</script>

<style lang="scss" scoped>
    @import "@/assets/custom.css";
</style>
```
- **동작 원리**: 컨테이너는 `align-center`(Vuetify 유틸, `align-items: center`)로 전체 아이템을 가운데 정렬해 두고, 각 아이템에 `align-self`를 따로 바인딩해 **부모의 `align-items`를 개별 아이템 단위로 덮어씁니다**.
- `auto`: 부모의 `align-items` 값을 그대로 따름 (여기서는 center)

### 3.2 Vite 개발 서버 프록시 (`vite.config.mts`의 `server` 부분 발췌)
```typescript
  server: {
    port: 3000,
    proxy: {
      '/api': {
        target: 'http://syntaxwiki.com:9993',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, '')
      }
    }
  },
```
- 프론트엔드 코드에서는 `/api/login/`처럼 **같은 출처(localhost:3000)** 로 요청하고, Vite 개발 서버가 이를 `http://syntaxwiki.com:9993/login/`으로 대신 전달합니다.
- `changeOrigin: true`: 요청 Host 헤더를 대상 서버 주소로 변경
- `rewrite`: 경로 앞의 `/api` 접두사를 제거
- **목적**: 브라우저의 CORS(교차 출처) 제한과 쿠키(세션) 전달 문제를 개발 단계에서 피하기 위함 (todolist에서는 `http://syntaxwiki.com:9993/...`을 직접 호출했었음)

### 3.3 Pinia 사용자 스토어 (`stores/user.js`)
```javascript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useUserStore = defineStore('user', () => {
    const sessionid = ref(sessionStorage.getItem('sessionid') || null)
    const login = (id) => {
        console.log('login', id)
        sessionid.value = id
        sessionStorage.setItem('sessionid', id)
    }

    const logout = () => {
        sessionid.value = null
        sessionStorage.removeItem('sessionid')
    }

    return {
        sessionid,
        isAuthenticated,
        login,
        logout
    }
})
```
- **Setup Store 문법**: `defineStore('id', () => { ... return {...} })` — 컴포넌트의 `<script setup>`처럼 `ref`(state), 함수(actions), `computed`(getters)를 정의하고 반환
- `sessionStorage`와 동기화: 새로고침해도 탭이 살아 있는 동안 세션 ID 유지, `login()`/`logout()`에서 저장·삭제
- 사용처: 2026-10-07 `login.vue`에서 `useUserStore().login(res.data.sessionid)` 호출

## 4. Vuetify 3 UI 연동 정리

| 컴포넌트 / prop | CSS Flexbox 대응 | 설명 |
|---|---|---|
| `<v-container>` | — | 가운데 정렬 + 반응형 최대폭 래퍼 |
| `<v-row>` | `display: flex; flex-wrap: wrap` | 그리드 행 (flex 컨테이너) |
| `<v-row justify="...">` | `justify-content` | start / center / end / space-around / space-between |
| `<v-row align="...">` | `align-items` | start / center / end |
| `<v-row no-gutters>` | — | 칼럼 사이 padding 제거 |
| `<v-col cols="n">` | `flex: 0 0 (n/12 × 100%)` | 12칸 중 n칸 |
| `<v-col>` (cols 없음) | `flex-grow: 1; flex-basis: 0` | 남은 폭 균등 분배 |
| `<v-col align-self="...">` | `align-self` | 칼럼 개별 세로 정렬 |
| `<v-sheet>` | — | 배경·모서리를 가진 기본 상자(종이) 컴포넌트 |
| `bg-surface-variant`, `bg-green`, `bg-red` | `background-color` | 테마/색상 유틸리티 |

## 6. 💡 핵심 문법 정리 표 (Key Takeaways)

| 개념 | 주요 기능 및 문법 예시 | 핵심 특징 |
|------|------------------------|-----------|
| **align-self** | `:style="{ alignSelf: 'flex-end' }"` | 부모 `align-items`를 아이템 하나만 덮어씀 |
| **Vuetify 12칸 그리드** | `<v-row><v-col cols="4">` | 한 행 = 12칸, cols 미지정 칼럼은 남은 폭 균등 분할 |
| **v-row justify / align** | `justify="space-between"`, `align="center"` | flex 정렬 속성을 prop으로 선언 |
| **v-col align-self** | `<v-col align-self="end">` | 칼럼 개별 세로 정렬 |
| **중첩 그리드** | `<v-col cols="8"><v-row><v-col cols="4">` | 부모 칼럼 폭 기준으로 다시 12분할 |
| **no-gutters** | `<v-row no-gutters>` | 칼럼 간 여백 제거 |
