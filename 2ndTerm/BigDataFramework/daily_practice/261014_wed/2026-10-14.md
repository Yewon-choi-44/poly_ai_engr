## 1. 실행 환경 및 진입 구조

- **프로젝트**: `blog/` — Vite + Vue 3 + Vuetify + TypeScript + Pinia + vue-i18n + unplugin-vue-router + vite-plugin-vue-layouts-next (2026-10-14 신규 생성)
- **진입 구조**: `main.ts` → `plugins/index.ts` → `App.vue`(`<v-app><v-main><router-view/></v-main></v-app>`) → 각 페이지가 `layouts/default.vue`로 감싸짐
- **API 서버**: `http://syntaxwiki.com:9993` (photosnaps와 달리 Vite 프록시 없이 **절대 URL로 직접 호출**, `vite.config.mts`의 `server`는 `port: 3000`만 설정)

### 1.1 페이지 흐름

```text
/ (index → Home)  ──[Blog 버튼]──▶  /Postlist  ──[New Card]──▶  /Post (작성)
                                        │
                                        └─[카드 더보기]──▶  /item/:itemid (상세)
```

### 1.2 파일 기반 라우팅 경로 매핑 (`typed-router.d.ts` 기준)

| 파일 경로 | 라우트 이름 | URL 경로 |
|-----------|-------------|----------|
| `pages/index.vue` | `/` | `/` |
| `pages/Home.vue` | `/Home` | `/Home` |
| `pages/Postlist.vue` | `/Postlist` | `/Postlist` |
| `pages/Postcard.vue` | `/Postcard` | `/Postcard` (컴포넌트지만 `pages/`에 있어 라우트로도 등록됨) |
| `pages/Post.vue` | `/Post` | `/Post` |
| `pages/item.[itemid].vue` | `/item.[itemid]` | `/item/:itemid` (동적 파라미터) |

### 3.2 `Postlist.vue` — 게시글 목록 (GET)
```vue
<template>
<v-container class="pa-10">
    <v-row>
        <v-col>
            <div class="text-h5 font-weight-bold">
                <VAvatar
                  color="grey"
                  size="36">
                  <v-img cover :src="picture"></v-img>
               </VAvatar>
            </div>
            <div class="ma-2">안녕하세요. {{ username }} 님!</div>
        </v-col>
        <v-col class="text-right" align-self="center">
            <v-btn
                variant="elevated" 
                class="text-none mr-5"
                @click="refresh">
                <v-icon>
                    mdi-refresh
                </v-icon>
            </v-btn>

            <v-btn
                variant="elevated" 
                color="red" 
                class="text-none mr-5"
                to="/Post">
                <span class="mr-2">
                    <v-icon class="mr-2">
                        mdi-plus
                    </v-icon>
                     New Card
                </span>
            </v-btn>
        </v-col>
    </v-row>

    <v-row justify-start class="mt-7">
        <!-- VHover 예제-->
        <Postcard v-for="item in cards" 
        :key="item.id" :item="item"></Postcard>
    </v-row>
</v-container>
</template>

<script setup>
    import { onMounted, ref } from 'vue'
    import axios from 'axios'
    import Postcard from './Postcard.vue';

    const cards = ref([{}])
    const username = ref('unknown')
    const picture = ref('https://cdn.vuetifyjs.com/images/profiles/marcus.jpg')
    
    const host = 'http://syntaxwiki.com:9993'
    

    const refresh = () => {
        axios.get(`${host}/blogposts/?format=json`,{ 
            //withCredentials: true
        }, {
        }).then(function(response) {
            cards.value = response.data.results
        })
    }

    const loadUser = () => {
      axios.get(`${host}`,{ }, {
        withCredentials: true
      })
      .then(function(res) {
        console.log(res)
        let user = res.data
        username.value = user.username
        picture.value = user.picture
    })}
    
    onMounted(() => {
        loadUser()
        refresh()
    })
</script>
<style scoped>
    .item {
        flex: 1 1 calc(50% - 10px);
        margin: 5px;
        box-sizing: border-box;
        display: flex;
    }

</style>
```
- **동작 원리**:
  - `onMounted`에서 `loadUser()`(사용자 정보)와 `refresh()`(게시글 목록)를 호출
  - `GET /blogposts/?format=json` 응답의 `response.data.results`(페이지네이션 응답의 결과 배열)를 `cards`에 넣으면, `<Postcard v-for>`가 카드 목록을 그림
  - 새로고침 버튼(`mdi-refresh`)으로 `refresh()`를 다시 호출해 목록 갱신
  - `New Card` 버튼은 `to="/Post"`로 작성 페이지로 이동
- **Props 전달**: `:item="item"`으로 게시글 객체 하나를 자식 `Postcard`에 넘김
- `<VAvatar>`: PascalCase 태그명도 Vuetify 컴포넌트로 인식됨 (`<v-avatar>`와 같음)
- todolist의 `ToDoList.vue` + `ToDoCard.vue` 구조(09-15)를 블로그용으로 응용한 형태

## 6. ⚠️ 코드 관찰 메모

코드는 수정하지 않았으며, 다음 실습 때 확인할 만한 부분만 기록합니다.

| 파일 | 내용 |
|---|---|
| `item.[itemid].vue` | 상태는 `items`로 선언했는데 응답 저장은 `item.value = res.data`로 하고 있어 `ReferenceError`가 나고 화면에 데이터가 채워지지 않음 |
| `item.[itemid].vue` | 요청 URL이 `http://syntaxwiki.com:9993/${itemid}` — 목록 API(`/blogposts/`)와 경로가 달라 게시글 상세 엔드포인트(`/blogposts/${itemid}/`로 추정)와 맞지 않을 수 있음 |
| `item.[itemid].vue` | `block= border` (속성 사이 `=` 잘못 위치), 상세 화면에 `<v-file-input>`(입력 컴포넌트)으로 파일명을 출력, "만료" 라벨에 `author`를 출력 — todolist에서 가져오며 남은 흔적으로 보임 |
| `Postcard.vue` | `<v-file>`은 Vuetify에 없는 컴포넌트(렌더링되지 않고 경고). `variant="mdi-book-open-page-variant"`는 유효한 variant 값이 아님 |
| `Postcard.vue` | `` :to="`item/${item.id}`" ``가 상대 경로라 `/Postlist`에서 누르면 `/item/...`, 다른 경로 깊이에서는 다르게 해석될 수 있음 (`/item/...` 절대 경로 권장) |
| `Postlist.vue` | `cards = ref([{}])` 초기값에 빈 객체가 있어 첫 렌더 때 내용 없는 카드 1장이 잠깐 표시됨. `loadUser()`는 `axios.get(host, {}, {withCredentials})`로 3번째 인자를 넘기지만 `get`은 인자를 2개만 받아 `withCredentials`가 무시됨 |
| `Post.vue` | `<n-date-input v-model="dueDate">`가 쓰였지만 이 프로젝트에 `NDateInput` 컴포넌트가 없고 `dueDate`도 선언되지 않음 (todolist에서 복사한 흔적) |
| `index.vue` | `</script>;` — 닫는 태그 뒤 세미콜론 |

## 7. 💡 핵심 문법 정리 표 (Key Takeaways)

| 개념 | 주요 기능 및 문법 예시 | 핵심 특징 |
|------|------------------------|-----------|
| **레이아웃 시스템** | `layouts/default.vue` + `setupLayouts(routes)` | 모든 페이지에 헤더·푸터 공통 적용 |
| **컴포넌트 자동 등록** | `src/components/AppHeader.vue` → `<AppHeader/>` | import 없이 사용, `components.d.ts` 자동 생성 |
| **REST GET 목록** | `axios.get(`${host}/blogposts/?format=json`).then(r => cards.value = r.data.results)` | 페이지네이션 응답의 `results` 배열 사용 |
| **REST POST multipart** | `axios.post(url, {..., picture1: file}, { headers: {'Content-Type': 'multipart/form-data'} })` | 파일 포함 게시글 등록 |
| **부모→자식 Props** | `<Postcard v-for="item in cards" :key="item.id" :item="item"/>`, `defineProps(['item'])` | 목록/카드 컴포넌트 분리 |
| **v-hover Scoped Slot** | `<v-hover v-slot="{ isHovering, props }">` + `v-bind="props"` | 호버 상태에 따른 UI 변화 |
| **v-overlay contained** | `:model-value="isHovering" contained` | 부모 카드 안에서만 덮개 표시 |
| **동적 라우트** | `item.[itemid].vue` → `/item/:itemid`, `useRoute().params.itemid` | URL 파라미터로 상세 조회 |
| **라우터 링크 버튼** | `<v-btn to="/Post">`, `` :to="`item/${id}`" `` | 선언적 페이지 이동 |
| **onMounted 초기 로딩** | `onMounted(() => { loadUser(); refresh() })` | 마운트 직후 데이터 요청 |
| **:deep() 선택자** | `.social-link :deep(.v-icon)` | scoped 스타일에서 자식 컴포넌트 내부 스타일링 |
