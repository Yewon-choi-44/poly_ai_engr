### 3.1 `position.vue` — relative / absolute 위치 지정

- **① relative vs absolute**: `position-relative` 상자는 원래 자리에서 `top/left`만큼 **밀려나되 원래 공간은 유지**, `position-absolute` 상자는 **문서 흐름에서 빠져나와** 가장 가까운 positioned 조상(없으면 페이지) 기준으로 배치됩니다.
- **② 부모 기준 absolute**: 부모(`.parent`)에 `position-relative`를 주면 자식들의 `top/left/right/bottom` 기준이 부모 상자가 됩니다. `child3`는 `right: 10px; bottom: 20px`로 부모 오른쪽 아래 모서리에 붙습니다.
- **③ 동적 위치**: `child2`의 `:style="{top: child2top + 'px', left: child2left + 'px'}"`를 `<v-number-input>` 두 개와 `v-model`로 연결해, 숫자를 올리고 내리면 child2가 실시간으로 움직입니다.
- **④ 조부모 기준 absolute**: 아래쪽 예제는 `.parent`에 `position-relative`가 **없고** `.grand-parent`에만 있으므로, 자식들이 부모가 아닌 **조부모 상자 기준**으로 배치되는 것을 보여줍니다 ("가장 가까운 positioned 조상" 규칙).
- Vuetify 유틸리티: `position-relative`, `position-absolute`, `border`, `border-dotted`, `border-orange`

### 3.2 `login.vue` — GSAP 스크린샷 슬라이드 + 세션 로그인
```vue
<template>
    <v-container class="d-flex align-center justify-center fill-height">
        <div class="screed mx-4 left">
            <img 
            v-for="(image, index) in images"
            :src="image"
            :key="index"
            ref="slides"
            class="screen-img"/>
        </div>
        <div class="mx-4 pa-4 right">
            <div class="border pa-4 login-right d-flex flex-column justify-center">
                <v-form @submit.prevent>
                    <v-text-field 
                        density="compact"
                        label="사용자이름"
                        variant="outlined"
                        v-model="form.username"
                        autocomplete="username">
                    </v-text-field>
                    <v-text-field
                        dentsity="compact"
                        label="비밀번호"
                        variant="outlined"
                        type="password"
                        v-model="form.password"
                        autocomplete="current-password"
                    ></v-text-field>
                    <v-btn 
                    text="로그인" 
                    variant="flat" 
                    color="indigo" 
                    @click="submit" 
                    block></v-btn>
                </v-form>
            </div>
            <div class="border pa-4 mt-4 d-flex justify-center">
                <div class="py-2">계정이 없으신가요?</div>
                <v-btn
                    variant="plain"
                    to="/signup">
                    <div class="signup-btn" >가입하기</div>
                </v-btn>
            </div>
        </div>
        <v-snackbar v-model="snackbar">
            {{  snackbarText }}
            <template v-slot:actions>
                <v-btn color="pink" variant="text"
                    @click="snackbar = false">
                    close
                </v-btn>
            </template>
        </v-snackbar>
    </v-container>
</template>

<script setup>
import axios from 'axios';
import gsap from 'gsap';
import {ref, onMounted, onUnmounted } from 'vue'
import { useRouter } from 'vue-router';
import { useUserStore } from '@/stores/user'

import screenshot1 from '@/assets/screenshot1-2x.png'
import screenshot2 from '@/assets/screenshot2-2x.png'
import screenshot3 from '@/assets/screenshot3-2x.png'
import screenshot4 from '@/assets/screenshot4-2x.png'

const images = [screenshot1, screenshot2, screenshot3, screenshot4];
const slides = ref([]);
let tl, ctx;

onMounted(() => {
    ctx = gsap.context((self) =>{
        tl = gsap.timeline({repeat: -1, repeatDelay: 1});
        slides.value.forEach((slide) => {
           tl.to(slide, { opacity: 1, duration: 1})
           .to(slide, { opacity: 0 , duration: 1}, "+=1");
       });
   });
});

onUnmounted(() => {
    ctx.revert();
});
const snackbar = ref(false)
const snackbarText = ref('')
const router = useRouter()

const form = ref({
    username: '',
    password: ''
})

const api = '/api/login/'

const submit = () => {
    axios.post(api, {
        username: form.value.username,
        password: form.value.password
    }, {
        withCredentials: true
    }).then((res) => {
        const userStore = useUserStore()
        userStore.login(res.data.sessionid)
        axios.defaults.headers.common['X-CSRFToken'] = res.data.csrftoken
        snackbarText.value = '로그인 성공'
        snackbar.value = true
        router.push({path: '/postlist' })
    }).catch((e) => {
        console.error(e)
        snackbarText.value = '로그인 정보를 바르게 입력하세요.'
        snackbar.value = true
    })
}
</script>

<style scoped>
    @import "@/assets/custom.css";
</style>
```
- **이미지 import**: Vite에서 `import screenshot1 from '@/assets/....png'`는 빌드 후 실제 URL 문자열을 돌려줍니다 → 배열로 묶어 `v-for`의 `:src`에 사용
- **v-for + Template Ref 배열**: `v-for` 안의 `ref="slides"`는 `slides.value`에 **렌더링된 `<img>` DOM 요소들의 배열**을 채워 줍니다.
- **GSAP 타임라인 슬라이드쇼**:
  - `gsap.timeline({ repeat: -1, repeatDelay: 1 })`: 무한 반복, 한 바퀴 끝날 때마다 1초 쉼
  - 각 슬라이드마다 `opacity 0→1`(1초) → **1초 유지**(`"+=1"` 위치 파라미터: 직전 애니메이션 끝 + 1초) → `opacity 1→0`(1초)을 이어 붙여 차례로 페이드 인·아웃
  - `gsap.context(...)` + `onUnmounted`의 `ctx.revert()`: 컨텍스트 안에서 만든 애니메이션을 페이지를 떠날 때 **한 번에 정리**(무한 반복 타임라인이 계속 도는 것을 방지)
- **로그인 흐름**:
  1. `axios.post('/api/login/', {username, password}, { withCredentials: true })` — 프록시를 거쳐 서버로 전달, 쿠키(세션) 주고받기 허용
  2. 성공 시 Pinia `useUserStore().login(res.data.sessionid)`로 세션 ID 저장(sessionStorage 동기화)
  3. `axios.defaults.headers.common['X-CSRFToken'] = res.data.csrftoken` — 이후 모든 axios 요청에 CSRF 토큰 헤더를 자동 첨부(Django 계열 서버의 CSRF 보호 대응)
  4. `router.push({ path: '/postlist' })`로 프로그래밍 방식 이동
- **`<v-form @submit.prevent>`**: Enter 키 등으로 폼이 제출될 때 브라우저 기본 새로고침을 막음
- **`<v-snackbar>` + `v-slot:actions`**: 화면 아래 알림 바, actions 슬롯에 닫기 버튼 배치

### 3.3 `signup.vue` — 회원가입 (multipart/form-data)
```vue
<template>
    <div class = "fill-height d-flex flex-column align-center justify-center">
        <div class="border d-flex flex-column justify-center pa-10 signup-box">
            <div class="logo my-10 align-self-center"></div>
            <div>가입하세요!</div>
            <v-form @submit.prevent>
                <v-text-field
                    density="compact" label="사용자 ID"
                    variant="outlined" v-model="form.username">
                </v-text-field>
            
                <v-text-field
                    density="compact" label="비밀번호"
                    variant="outlined" v-model="form.password1">
                </v-text-field>

                <v-text-field
                    density="compact" label="사용자이름"
                    variant="outlined" v-model="form.first_name">
                </v-text-field>

                <v-file-input
                    v-model="files" prepend-icon=""
                    density="compact" variant="outlined"
                    append-inner-icon="mdi-image-search"
                    label="프로필 사진">
                </v-file-input>

                <v-btn
                    text="가입" variant="flat" color="indigo" @click="submit" block>
                </v-btn>
        </v-form>
    </div>
    <div class="border mt-5 pa-8 signup-box d-flex justify-center">
        <div class="py-2">계정이 있으신가요?</div>
        <v-btn variant="plain" to="/login">
            <div class="login-btn">로그인</div>
        </v-btn>
    </div>
    </div>

    <v-snackbar v-model="snackbar">
        {{  snackbarText }}
        <template v-slot:actions>
            <v-btn color="pink" variant="text"
            @click="snackbar = false">Close</v-btn> 
        </template>
    </v-snackbar>
</template>

<script setup>
    import { ref } from 'vue'
    import axios from 'axios'
    const form = ref({
        username: '',
        password1: '',
        password2: '',
        first_name: ''
    })

    const files = ref([])
    const snackbar = ref(false)
    const snackbarText = ref('')
    const isEmpty = value => {
        if (value === null || value === undefined || value === '')
            return true
        return !!(Array.isArray(value) && value.length === 0)
    }

    const host = '/api'
    const api = '/authuser/'
    const submit = () => {
        form.value.password2 = form.value.password1;
        if(isEmpty(form.value.username)) {
            snackbarText.value = '유저명을 입력해주세요.'
            snackbar.value = true
        } else if(isEmpty(form.value.password1)) {
            snackbarText.value = '비밀번호를 입력해주세요.'
            snackbar.value = true
        } else if(form.value.password1 != form.value.password2) {
            snackbarText.value = '비밀번호와 확인이 다릅니다.'
            snackbar.value = true
        } else {
            axios.post(`${host}${api}`, {...form.value, picture: files.value}, {
                headers: {
                    'Content-Type': 'multipart/form-data'
                }
            }).then(() => {
                snackbarText.value = '계정이 생성되었습니다.'
                snackbar.value = true
            }).catch((error) => {
                alert(error.response.data)
            })
        }
    }
</script>

<style scoped>
    @import "@/assets/custom.css";
</style>
```
- **레이아웃**: `d-flex flex-column align-center justify-center` + `.logo`에 `align-self-center` — Flexbox 실습 내용을 그대로 적용
- **클라이언트 검증 함수 `isEmpty`**: `null`/`undefined`/빈 문자열/빈 배열을 모두 "비어 있음"으로 판정
- 화면에 비밀번호 확인 칸이 없어서 `password2 = password1`로 복사한 뒤 서버(`password1`, `password2`를 요구하는 API)에 함께 전송
- **multipart 업로드**: `{...form.value, picture: files.value}` — 스프레드로 폼 필드를 펼치고 파일 필드를 추가. axios는 `Content-Type: multipart/form-data` 헤더가 있으면 일반 객체를 **FormData로 자동 변환**합니다(todolist `RegisterAccount.vue`와 같은 방식).
- 요청 URL: `` `${host}${api}` `` = `/api/authuser/` → 프록시 → `http://syntaxwiki.com:9993/authuser/`

```vue
                ></v-text-field>
                <v-textarea
                    v-model="content" label="content" density="outlined"
                    variant="outlined" prepend-icon="mdi-content-paste" clearable
                ></v-textarea>
                <v-text-field
                    v-model="author" density="compact" variant="outlined"
                    prepend-icon="mdi-account-circle-outline" label="author"
                ></v-text-field>
                <v-row>
                    <v-spacer></v-spacer>
                    <v-btn
                        variant="elevated" color="blue"
                        class="text-none ma-2" @click="submitForm"
                        prepend-icon="mdi-plus">공유
                    </v-btn>
                    <v-btn
                        variant="elevated" class="text-none ma-2"
                        to="/postlist" prepend-icon="mdi-close">닫기
                    </v-btn>
                </v-row>
            </v-form>
        </v-sheet>
    </v-container>
</template>

<script setup>
    import { ref } from 'vue'
    import axios from 'axios'

    const title = ref('')
    const content = ref('')
    const author - ref('')
    const pictures = ref([])
    const preview = ref()
    const previewH = ref(0)
    const onFileChange = (event) => {
        if(event.target.files.length > 5) {
            pictures.value = []
            alert('사진을 5개 이하만 선택할 수 있습니다.')
            return
        }
        const file = event.target.files[0];
        if (file) {
            const reader = new FileReader();

            reader.onload = (e) => {
                previewH.value = 250
                preview.value = e.target.result;
            };
            reader.readAsDataURL(file);
        }
    }
    const submitForm = () => {
        axios.post('/api/posts/', {
            title: title.value,
            content: content.value,
            author: author.value,
            pictures: pictures.value
        }, {
            headers: {
                'Content-Type': 'multipart/form-data'
            }
        }).then((res) => {
            alert('성공')
        }).catch(error) => {
            alert('실패')
        })
    }
</script>
```
- **설계 의도**:
  - `<v-file-input multiple chips>`: 여러 장 선택, 선택한 파일을 칩 형태로 표시
  - `@change="onFileChange"`: 5장을 넘으면 선택을 비우고 경고
  - **FileReader 미리보기**: `reader.readAsDataURL(file)`로 첫 번째 파일을 Base64 Data URL로 읽고, `onload`에서 `preview`에 넣어 `<v-img :src="preview">`로 즉시 표시. 미리보기 전에는 `previewH = 0`으로 숨겨 두었다가 250px로 키움
  - 제출 시 `/api/posts/`로 multipart 전송
- 현재 상태로는 아래 6번의 문법 오류 때문에 컴파일되지 않는 **작성 중 코드**입니다.

## 6. ⚠️ 코드 관찰 메모

코드는 수정하지 않았으며, 다음 실습 때 확인할 만한 부분만 기록합니다.

| 파일 | 내용 |
|---|---|
| `post.vue` | `const author - ref('')` — `=` 대신 `-`가 들어가 문법 오류(컴파일 실패) |
| `post.vue` | `}).catch(error) => {` — 화살표 함수 괄호가 어긋남. `.catch((error) => {` 형태가 의도된 것으로 보임 |
| `post.vue` | `<script setup lang="ts">` 블록이 하나 더 있고 `import { preview } from 'vite'`를 가져옴 → 아래 `<script setup>`의 `const preview = ref()`와 이름이 겹치고, `<script setup>`은 컴포넌트당 하나만 허용됨 |
| `post.vue` | `<v-textarea density="outlined">` — density 값은 `default`/`comfortable`/`compact` 중 하나 |
| `login.vue` | `class="screed mx-4 left"` — CSS 클래스명은 `.screen`(휴대폰 프레임 배경)이라 프레임 배경이 적용되지 않음. 비밀번호 필드의 `dentsity` 오타(`density`) |
| `login.vue` | 스토어 사용 시 `stores/user.js`의 미정의 `isAuthenticated` 때문에 로그인 성공 처리 중 오류가 날 수 있음 (2026-09-30 문서 5번 참고) |
| `position.vue` | 두 번째 `<v-number-input>`의 라벨이 `top(px)` (left용), 스타일의 `.grant-parent`는 템플릿 클래스 `.grand-parent`와 철자가 달라 빨간 테두리가 적용되지 않음, `.box-orange`가 두 번 정의됨 |
| `signup.vue` | 비밀번호 필드에 `type="password"`가 없어 입력값이 그대로 보임 |

## 7. 💡 핵심 문법 정리 표 (Key Takeaways)

| 개념 | 주요 기능 및 문법 예시 | 핵심 특징 |
|------|------------------------|-----------|
| **position: relative** | `class="position-relative" style="top:20px"` | 원래 자리 기준으로 이동, 공간 유지, 자식 absolute의 기준점 |
| **position: absolute** | `class="position-absolute" style="right:10px; bottom:20px"` | 흐름에서 빠짐, 가장 가까운 positioned 조상 기준 |
| **CSS 스프라이트** | `background-image` + `background-position: 0 -2959px` | 큰 이미지 한 장에서 일부만 잘라 표시 |
| **Vite 이미지 import** | `import img from '@/assets/a.png'` | 빌드된 이미지 URL 문자열을 얻음 |
| **v-for 안의 ref** | `<img v-for ... ref="slides">` → `slides.value` 배열 | 반복 렌더링된 DOM 요소 목록 획득 |
| **GSAP timeline** | `gsap.timeline({repeat:-1, repeatDelay:1})`, `.to(el, {...}, "+=1")` | 순차 애니메이션, 위치 파라미터로 간격 조절 |
| **gsap.context / revert** | `ctx = gsap.context(() => {...})`, `onUnmounted(() => ctx.revert())` | 컴포넌트 해제 시 애니메이션 일괄 정리 |
| **axios withCredentials** | `axios.post(url, data, { withCredentials: true })` | 쿠키(세션) 포함 요청 |
| **axios 기본 헤더** | `axios.defaults.headers.common['X-CSRFToken'] = token` | 이후 모든 요청에 CSRF 토큰 자동 첨부 |
| **useRouter().push** | `router.push({ path: '/postlist' })` | 코드로 페이지 이동 |
| **Pinia 스토어 사용** | `const userStore = useUserStore(); userStore.login(id)` | 전역 로그인 상태 저장 |
| **multipart/form-data** | `axios.post(url, {...form, picture: files}, { headers: {'Content-Type': 'multipart/form-data'} })` | 객체를 FormData로 자동 변환해 파일 업로드 |
| **FileReader** | `reader.readAsDataURL(file)`, `reader.onload = e => e.target.result` | 업로드 전 이미지 미리보기 |
| **@submit.prevent** | `<v-form @submit.prevent>` | 폼 기본 제출(새로고침) 방지 |
