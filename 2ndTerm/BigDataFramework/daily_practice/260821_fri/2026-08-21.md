## 2. 실습 1: 텍스트 보간법 (Text Interpolation)

`ref()`를 사용하여 반응형 문자열 데이터를 선언하고, Mustache 문법(`{{ }}`)으로 화면에 렌더링하는 실습입니다.

### 🧩 자식 컴포넌트: `TextInterpolation.vue`
```vue
<template>
  <span>Message: {{ msg }}</span>
</template>

<script lang="js" setup>
import { ref } from 'vue';

// ref(): 반응형 상태 생성
const msg = ref("Hello");
</script>
```

### 🏠 부모 컴포넌트: `App.vue` (호출 및 렌더링)
```vue
<script lang="js" setup>
import TextInterpolation from "./TextInterpolation.vue";
</script>

<template>
  <TextInterpolation />
</template>

<style scoped>
</style>
```

## 3. 실습 2: 반응형 버튼 카운터 (Button Counter)

버튼 클릭 이벤트(`@click`)에 따라 반응형 변수(`count`, `count1`)의 값이 실시간으로 증감하도록 구현한 컴포넌트 실습입니다.

### 🧩 자식 컴포넌트: `ButtonCounter.vue`
```vue
<script lang="js" setup> // 자바스크립트 코드임을 명시 
import { ref } from 'vue' 

// ref() : 반응형 데이터로 만들어주는 함수
const count = ref(0) 
const count1 = ref(0)
</script>

<template>
  <!-- @click 이벤트와 {{ }} 텍스트 보간법 -->
  <button @click="count++">당신은 {{ count }} 번 클릭했습니다.</button>
  <div></div>
  <button @click="count1--">당신은 {{ count1 }} 번 클릭했습니다.</button>
</template>
```

### 🏠 부모 컴포넌트: `App.vue` (호출 및 렌더링)
```vue
<script setup>
import ButtonCounter from "./ButtonCounter.vue";
</script>

<template>
  <h1>아래에 자식 컴포넌트가 있습니다.</h1>
  <div></div>
  <ButtonCounter />  
</template>
```

## 4. 실습 3: 원시 HTML 렌더링 (Raw HTML & v-html)

일반 텍스트 보간법(`{{ }}`)과 `v-html` 디렉티브의 차이점을 확인하는 실습입니다. `{{ }}`는 HTML 코드를 일반 텍스트로 이스케이프하여 출력하지만, `v-html`은 실제 HTML 태그로 파싱하여 렌더링합니다.

### 🧩 자식 컴포넌트: `RawHTML.vue` (`exam1/src/components/RawHTML.vue`)
```vue
<template> 
    <!-- 텍스트 보간법: HTML 태그 문자열 그대로 노출 -->
    <p> 텍스트 보간법 사용: {{ rawHtml }} </p>
    <br>
    <!-- v-html 디렉티브: 실제 HTML 마크업으로 해석되어 렌더링 -->
    <p> v-html 디렉티브 사용: <span v-html="rawHtml"></span></p>
</template>

<script lang="js" setup>
    import { ref } from 'vue';
    const rawHtml = '<span style="color:red">이것은 빨간색이어야 합니다.</span>';
</script>

<style>
</style>
```

### 🏠 부모 컴포넌트: `App.vue` (호출 및 렌더링)
```vue
<script lang="js" setup>
  import RawText from "./components/RawHTML.vue";
</script>

<template>
  <RawText />
</template>

<style>
</style>
```

## 5. 실습 4: 속성 바인딩 기본 (Attribute Binding - v-bind)

HTML 태그의 속성(Attribute)에 동적 데이터를 바인딩할 때 사용하는 `v-bind` 문법 실습입니다.

- `v-bind:id="dynamicId1"`: 전체 문법
- `:id="id"`: 축약형(Shorthand) 문법
- `v-bind:id`: 속성명과 변수명이 동일할 때 사용하는 동일 이름 축약형

### 🧩 자식 컴포넌트: `AttrBind1.vue` (`exam1/src/components/AttrBind1.vue`)
```vue
<template>
<div>
    <div v-bind:id="dynamicId1">{{ dynamicId1 }}</div>
    <div :id="id">{{ id }}</div>
    <div v-bind:id>{{ id }}</div>
    <div v-bind:id="id">{{ id }}</div>
</div>
</template>

<script lang="js" setup>
    import { ref } from 'vue';
    const dynamicId1 = "div1";
    const id = "div2";
</script>
```

### 🏠 부모 컴포넌트: `App.vue` (호출 및 렌더링)
```vue
<script lang="js" setup>
  import AttrBind1 from "./components/AttrBind1.vue";
</script>

<template>
  <AttrBind1 />
</template>
```

## 6. 실습 5: 불리언 속성 바인딩 (Boolean Attributes - :disabled)

버튼의 `disabled` 속성 등 존재 여부 자체가 참/거짓을 결정하는 불리언 속성의 바인딩 동작 방식을 테스트하는 실습입니다.

- **Falsy 값 (`false`, `null`, `undefined`, `0`)**: 속성이 포함되지 않아 버튼이 활성화 상태 유지
- **Truthy 값 (`true`, `""` 빈 문자열, `"true"` 문자열)**: 속성이 포함되어 버튼이 비활성화(`disabled`)됨

### 🧩 자식 컴포넌트: `AttrBind2.vue` (`exam1/src/components/AttrBind2.vue`)
```vue
<template>
    <div>
        <!-- False 계열 (버튼 활성화) -->
        <button :disabled="isButtonDisabledf1">False 버튼1 - {{ isButtonDisabledf1 }}</button>
        <button :disabled="isButtonDisabledf2">False 버튼2 - {{ isButtonDisabledf2 }}</button>
        <button :disabled="isButtonDisabledf3">False 버튼3 - {{ isButtonDisabledf3 }}</button>
        <button :disabled="isButtonDisabledf4">False 버튼4 - {{ isButtonDisabledf4 }}</button>
    </div>
    <div>
        <!-- True 계열 (버튼 비활성화) -->
        <button :disabled="isButtonDisabledt1">True 버튼1 - {{ isButtonDisabledt1 }}</button>
        <button :disabled="isButtonDisabledt2">True 버튼2 - {{ isButtonDisabledt2 }}</button>
        <button :disabled="isButtonDisabledt3">True 버튼3 - {{ isButtonDisabledt3 }}</button>
    </div>
</template>

<script lang="js" setup>
    import { ref } from 'vue'
    const isButtonDisabledf1 = ref(false)
    const isButtonDisabledf2 = ref(null)
    const isButtonDisabledf3 = ref(undefined)
    const isButtonDisabledf4 = ref(0)
    
    const isButtonDisabledt1 = ref(true)
    const isButtonDisabledt2 = ref("")
    const isButtonDisabledt3 = ref("true")
</script>

<style scoped>
    div {
        display: flex;
        flex-direction: column;
    }
    button {
        margin: 5px;
    }
</style>
```

### 🏠 부모 컴포넌트: `App.vue` (호출 및 렌더링)
```vue
<script lang="js" setup>
  import AttrBind2 from "./components/AttrBind2.vue";
</script>

<template>
  <AttrBind2 />
</template>
```

## 7. 💡 핵심 문법 정리 (Key Takeaways)

| 문법 / 디렉티브 | 설명 | 예시 |
|---|---|---|
| `<script setup>` | Vue 3 Composition API의 간결한 SFC 작성 구문 | `<script setup>` |
| `ref(초기값)` | 원시값을 반응형 객체로 래핑하여 상태 변화 감지 및 UI 자동 갱신 | `const count = ref(0)` |
| `{{ expression }}` | 텍스트 보간법. HTML을 이스케이프하여 일반 텍스트로 안전하게 출력 | `<span>{{ msg }}</span>` |
| `v-html="htmlString"` | 문자열을 실제 HTML DOM으로 파싱하여 렌더링 (XSS 보안 주의) | `<span v-html="rawHtml">` |
| `v-bind:attr="val"` 또는 `:attr="val"` | HTML 속성에 동적 자바스크립트 표현식/변수 바인딩 | `<div :id="id">` |
| `:attr` (동일 이름 축약) | 속성명과 변수명이 같을 때 단축 표기 (Vue 3.4+) | `<div :id>` 또는 `<div v-bind:id>` |
| `:disabled="condition"` | 불리언 속성 바인딩. Truthy 값(빈 문자열 포함)일 때 속성 적용, Falsy일 때 속성 제거 | `<button :disabled="isPending">` |
| `@click="..."` | `v-on:click`의 축약형. 클릭 이벤트 핸들러 연결 | `<button @click="count++">` |
| 컴포넌트 등록 | `<script setup>` 내에서 `import` 시 템플릿 태그로 즉시 사용 가능 | `import Child from './Child.vue'` |
