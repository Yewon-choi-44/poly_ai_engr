## 1. 실행 환경 및 진입 구조

- **프로젝트**: `simpleblog/` — Vite + Vue 3 + Vuetify + TypeScript + Pinia + vue-i18n + vue-router 파일 기반 라우팅
- **추가 의존성 없음**: `axios`, `gsap`은 아직 설치되지 않았습니다.

| 파일 경로 | URL 경로 |
|-----------|----------|
| `pages/index.vue` | `/` (스캐폴딩 기본 `HelloWorld`) |

### 1.1 엔트리 스크립트 (`main.ts`)
```typescript
/**
 * main.ts
 *
 * Bootstraps Vuetify and other plugins then mounts the App`
 */

// Composables
import { createApp } from 'vue'

// Plugins
import { registerPlugins } from '@/plugins'

// Components
import App from './App.vue'

// Styles
import 'unfonts.css'

const app = createApp(App)

registerPlugins(app)

app.mount('#app')
```

### 1.2 루트 컴포넌트 (`App.vue`)

    <v-main>
      <router-view />

</template>

</script>

## 3. 스크립트 및 설정 파일 (*.ts, *.mts)

### 3.1 `router/index.ts`
```typescript
/**
 * router/index.ts
 *
 * Automatic routes for ./src/pages/*.vue
 */

// Composables
import { createRouter, createWebHistory } from 'vue-router'
import { routes } from 'vue-router/auto-routes'

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes,
})

export default router
```
- `blog`/`photosnaps`와 달리 `setupLayouts(routes)` 없이 **자동 생성 라우트를 그대로** 사용합니다.

### 3.2 `vite.config.mts`
```typescript
import VueRouter from 'vue-router/vite';
import { fileURLToPath, URL } from 'node:url'
import Vue from '@vitejs/plugin-vue'
import Fonts from 'unplugin-fonts/vite'
import { defineConfig } from 'vite'
import Vuetify, { transformAssetUrls } from 'vite-plugin-vuetify'

// https://vitejs.dev/config/
export default defineConfig({
  plugins: [VueRouter({ dts: 'src/typed-router.d.ts' }), Vue({
    template: { transformAssetUrls },
  }), // https://github.com/vuetifyjs/vuetify-loader/tree/master/packages/vite-plugin#readme
  Vuetify({
    autoImport: true,
    styles: {
      configFile: 'src/styles/settings.scss',
    },
  }), Fonts({
    fontsource: {
      families: [
        {
          name: 'Roboto',
          weights: [100, 300, 400, 500, 700, 900],
          styles: ['normal', 'italic'],
        },
      ],
    },
  })],
  define: { 'process.env': {} },
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('src', import.meta.url)),
    },
    extensions: [
      '.js',
      '.json',
      '.jsx',
      '.mjs',
      '.ts',
      '.tsx',
      '.vue',
    ],
  },
  server: {
    port: 3000,
  },
})
```
- `VueRouter({ dts })`: `src/pages/` 기반 자동 라우팅 + 타입 파일 생성
- `Vuetify({ autoImport: true })`: 사용한 `v-*` 컴포넌트만 자동 import (트리 쉐이킹)
- `Fonts`: Roboto 웹폰트 로딩
- `resolve.alias['@']`: `@/` → `src/`

## 4. blog 프로젝트와의 구성 비교

`vite.config.mts`를 `blog/vite.config.mts`와 비교하면 차이는 다음 두 플러그인뿐입니다.

| 항목 | `blog` (10-14) | `simpleblog` (10-21) |
|---|---|---|
| `vite-plugin-vue-layouts-next` (`Layouts()`) | ✅ 사용 → `layouts/default.vue`로 페이지 감쌈 | ❌ 없음 |
| `unplugin-vue-components` (`Components({ dts })`) | ✅ 사용 → `components/` 자동 등록, `components.d.ts` 생성 | ❌ 없음 → 직접 import 필요 |
| `router/index.ts` | `routes: setupLayouts(routes)` | `routes` |
| `src/components.d.ts` | 있음 | 없음 |

즉 Vuetify 프로젝트 생성기에서 Layouts/Components 기능을 선택하지 않은 "simple" 구성으로 프로젝트를 만든 것입니다.

## 5. 💡 핵심 문법 정리 표 (Key Takeaways)

| 개념 | 주요 기능 및 문법 예시 | 핵심 특징 |
|------|------------------------|-----------|
| **Vite 플러그인 구성** | `plugins: [VueRouter(), Vue(), Vuetify(), Fonts()]` | 선택한 기능에 따라 플러그인이 달라짐 |
| **파일 기반 라우팅** | `VueRouter({ dts: 'src/typed-router.d.ts' })` + `import { routes } from 'vue-router/auto-routes'` | `pages/` 구조가 곧 URL |
| **레이아웃 플러그인 유무** | `setupLayouts(routes)` vs `routes` | 레이아웃 플러그인이 있어야 `layouts/` 폴더가 동작 |
| **컴포넌트 자동 등록 유무** | `Components({ dts })` 없으면 `import HelloWorld from '@/components/HelloWorld.vue'` | 자동 등록이 없으면 명시적 import |
| **Vuetify autoImport** | `Vuetify({ autoImport: true })` | `v-*` 컴포넌트는 플러그인과 무관하게 자동 import |
| **경로 별칭** | `'@': fileURLToPath(new URL('src', import.meta.url))` | `@/...`로 src 기준 경로 사용 |
