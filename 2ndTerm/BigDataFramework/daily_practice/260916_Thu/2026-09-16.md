## 1. 실행 환경 및 진입 구조

`todolist`와 `flexblog` 프로젝트는 모두 **Vite + Vue 3 (Composition API) + Vuetify 3 + TypeScript + Pinia + unplugin-vue-router** 기반으로 구성되어 있습니다.

### 1.1 엔트리 스크립트 (`main.ts`) — todolist / flexblog 공통
```typescript
import { createApp } from 'vue'
import { registerPlugins } from '@/plugins'
import App from './App.vue'
import 'unfonts.css'

const app = createApp(App)
registerPlugins(app)
app.mount('#app')
```

### 1.2 플러그인 레지스트리 (`plugins/index.ts`) — todolist / flexblog 공통
```typescript
import router from '../router'
import i18n from './i18n'
import { createPinia } from 'pinia'
import type { App } from 'vue'
import vuetify from './vuetify'

export function registerPlugins (app: App) {
  app.use(vuetify)
  app.use(createPinia())
  app.use(i18n)
  app.use(router)
}
```
- `Vuetify` → UI 컴포넌트 라이브러리 전역 등록
- `Pinia` → 전역 상태 관리(createPinia()로 인스턴스 생성 후 등록)
- `i18n` → 다국어 플러그인 등록
- `router` → 파일 기반 라우팅 등록

### 1.3 루트 뷰 컴포넌트 (`App.vue`) — todolist / flexblog 공통
```vue
<template>
  <v-app>
    <v-main>
      <router-view />
    </v-main>
  </v-app>
</template>

<script lang="ts" setup>
  //
</script>
```
- `<v-app>`: Vuetify 3의 최상위 레이아웃 래퍼. 테마, RTL, 반응형 브레이크포인트를 전역 관리함
- `<router-view />`: 현재 URL 경로에 매핑된 페이지 컴포넌트를 동적으로 렌더링

### 1.4 파일 기반 라우팅 구조 (`todolist`)

## 2. todolist — 개별 실습 및 페이지 컴포넌트 (*.vue)

### 2.1 Transition 기초 (`TransitionBasic.vue`)
- **주요 기능**: `<transition>` 컴포넌트로 `v-if` 조건 변경 시 `fade` 애니메이션을 적용합니다.

```vue
<template>
  <v-btn @click="show = !show">Toggle</v-btn>
  <transition name="fade">
    <p v-if="show">Hello Vue!</p>
  </transition>
</template>

<script setup>
import { ref } from 'vue'
const show = ref(true)
</script>

<style scoped>
.fade-enter-active, .fade-leave-active { transition: opacity 0.5s ease; }
.fade-enter-from, .fade-leave-to { opacity: 0; }
</style>
```
- `name="fade"` → Vue가 자동으로 `.fade-enter-active`, `.fade-leave-active`, `.fade-enter-from`, `.fade-leave-to` CSS 클래스를 적용함

---

### 2.2 CSS Transition 클래스 직접 지정

**`CssTransition.vue`**: `enter-active-class`, `leave-active-class`에 Animate.css 클래스를 직접 지정하여 외부 애니메이션 라이브러리를 연동합니다.

```vue
<transition
  enter-active-class="animate__animated animate__bounceIn"
  leave-active-class="animate__animated animate__bounceOut">
  <p v-if="show">Hello</p>
</transition>
```

**`CustomTransitionClass.vue`**: 사용자 정의 클래스 이름을 `enter-from-class`, `enter-to-class` 등으로 세밀하게 제어합니다.

---

### 2.3 Transition Duration & Elements

**`TransitionDuration.vue`**: `:duration="{ enter: 500, leave: 800 }"` 속성으로 진입/퇴장 지속 시간을 밀리초 단위로 명시적으로 설정합니다.

**`TransitionElements.vue`**: `<transition>` 내에서 두 요소를 전환할 때 `mode="out-in"`을 사용하여 먼저 나가고 난 후 새 요소가 진입하도록 순서를 제어합니다.

```vue
<transition name="fade" mode="out-in">
  <button v-if="isEditing" key="save">Save</button>
  <button v-else key="edit">Edit</button>
</transition>
```
- `mode="out-in"`: 현재 요소가 먼저 퇴장 완료된 후 새 요소가 진입 → 겹침 없는 전환
- `key` 속성: 동일 태그 요소를 Vue가 구별할 수 있게 해줌

---

### 2.4 Transition Hooks (JS Hook) (`TransitionHooks.vue`)
- **주요 기능**: CSS 클래스가 아닌 JavaScript 이벤트 훅(`@before-enter`, `@enter`, `@leave` 등)을 사용하여 애니메이션 로직을 코드로 직접 제어합니다.

```vue
<template>
  <transition
    @before-enter="beforeEnter"
    @enter="onEnter"
    @leave="onLeave"
    :css="false">
    <div v-if="show">...</div>
  </transition>
</template>

<script setup>
const beforeEnter = (el) => { el.style.opacity = 0 }
const onEnter = (el, done) => {
  // 직접 애니메이션 라이브러리 호출 후 done() 실행
  done()
}
const onLeave = (el, done) => { done() }
</script>
```
- `:css="false"`: Vue의 CSS 클래스 기반 처리를 비활성화하여 JS 훅만으로 전적으로 제어
- `done()` 콜백: 비동기 애니메이션 완료 시점을 Vue에 알려줘야 다음 단계로 진행

---

### 2.5 Slide & Nested Transition

**`SlideTransition.vue`**: `transform: translateX()` 기반의 슬라이드 효과를 CSS와 `<transition>`으로 구현합니다.

**`NestedTransition.vue`**: 부모 `<transition>`과 자식 요소의 중첩 애니메이션을 `:duration`으로 타이밍을 맞춥니다.

```vue
<transition name="nested">
  <div v-if="show" class="outer">
    <div class="inner">Hello</div>
  </div>
</transition>
```
```css
/* 중첩 자식 요소는 부모 transition 클래스 하위에서 별도 딜레이 적용 */
.nested-enter-active .inner { transition-delay: 0.25s; }
```

### 2.6 TransitionGroup 실습 (`TransitionGroupExam1~3.vue`)
- **주요 기능**: `<transition-group>`을 사용하여 `v-for` 리스트의 항목 추가/삭제 시 각 항목에 개별 애니메이션을 적용합니다.

```vue
<template>
  <transition-group name="list" tag="ul">
    <li v-for="item in items" :key="item">{{ item }}</li>
  </transition-group>
  <button @click="add">Add</button>
  <button @click="remove">Remove</button>
</template>

<style scoped>
.list-enter-active, .list-leave-active { transition: all 0.5s ease; }
.list-enter-from, .list-leave-to { opacity: 0; transform: translateX(30px); }
/* FLIP 기법: 위치 이동 시에도 부드럽게 */
.list-move { transition: transform 0.5s ease; }
</style>
```
- `<transition>` vs `<transition-group>` 핵심 차이:
  - `<transition>`: 단일 요소/컴포넌트 진입·퇴장 제어
  - `<transition-group>`: 리스트 항목들 각각에 개별 애니메이션 + `.list-move` FLIP 이동 애니메이션 지원
- `tag="ul"`: `<transition-group>` 자체가 렌더링할 HTML 태그 지정 (기본값: `<span>`)

### 2.7 GSAP 연동 Transition (`TransitionGsap.vue`, `GsapFromTo.vue`)
- **주요 기능**: JavaScript Transition Hook과 [GSAP(GreenSock)](https://gsap.com/) 라이브러리를 연동하여 고급 이징 애니메이션을 구현합니다.

```vue
<template>
  <transition @enter="onEnter" @leave="onLeave" :css="false">
    <div v-if="show" class="box"></div>
  </transition>
</template>

<script setup>
import gsap from 'gsap'

const onEnter = (el, done) => {
  gsap.from(el, { duration: 0.8, opacity: 0, y: -60, ease: 'bounce.out', onComplete: done })
}
const onLeave = (el, done) => {
  gsap.to(el, { duration: 0.5, opacity: 0, y: 60, onComplete: done })
}
</script>
```

**`GsapFromTo.vue`**: `gsap.fromTo()`를 사용하여 시작 상태와 끝 상태를 모두 명시적으로 지정합니다.
```javascript
gsap.fromTo(el,
  { opacity: 0, scale: 0.5 },    // from
  { opacity: 1, scale: 1, duration: 1, onComplete: done } // to
)
```

### 2.8 GSAP 404 페이지 (`Gsap404Page.vue`)
- **주요 기능**: `onMounted` 훅에서 GSAP 타임라인(`gsap.timeline()`)을 사용하여 404 페이지 진입 시 텍스트와 요소들이 순차적으로 등장하는 애니메이션을 구현합니다.

```vue
<template>
  <div ref="container">
    <h1 ref="title">404</h1>
    <p ref="subtitle">페이지를 찾을 수 없습니다.</p>
    <v-btn ref="btn" to="/">홈으로</v-btn>
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import gsap from 'gsap'

const title = ref(null)
const subtitle = ref(null)
const btn = ref(null)

onMounted(() => {
  const tl = gsap.timeline()
  tl.from(title.value, { y: -100, opacity: 0, duration: 0.6 })
    .from(subtitle.value, { y: 30, opacity: 0, duration: 0.5 }, '-=0.2')
    .from(btn.value.$el, { scale: 0, opacity: 0, duration: 0.4 })
})
</script>
```
- `gsap.timeline()`: 애니메이션을 순차/병렬로 체이닝 가능한 타임라인 인스턴스
- `'-=0.2'`: 이전 애니메이션 종료 0.2초 전에 겹쳐서 시작하는 오프셋 지정

### 2.9 Named Scoped Slot 심화 (`NamedScopedSlot.vue`, `FancyList.vue`)
- **주요 기능**: 자식 컴포넌트(`FancyList.vue`)가 여러 개의 이름 있는 Scoped Slot(`#item`, `#more`)을 제공하고, 부모가 각 슬롯에 커스텀 UI와 내부 함수를 바인딩합니다.

**`FancyList.vue`** (자식 — Slot 제공자):
```vue
<template>
  <ul>
    <li v-if="isLoading">Loading...</li>
    <li v-for="item in items">
      <!-- name="item" 슬롯에 item 객체 전체를 바인딩 -->
      <slot name="item" v-bind="item"></slot>
    </li>
  </ul>
  <!-- name="more" 슬롯에 load 함수를 바인딩 -->
  <slot name="more" :load="load"></slot>
</template>

<script setup>
import { onMounted, ref } from 'vue'
const props = defineProps(['api-url', 'per-page'])
const items = ref([])
const isLoading = ref(true)
const load = () => {
  isLoading.value = true
  setTimeout(() => {
    items.value.push(...[
      { body: 'Scoped Slots Guide', username: 'Evan You', likes: 20 },
      { body: 'Vue Tutorial', username: 'Natalia Tepluhina', likes: 10 }
    ])
    isLoading.value = false
  }, 1000)
}
onMounted(() => { load() })
</script>
```

**`NamedScopedSlot.vue`** (부모 — Slot 소비자):
```vue
<template>
  <FancyList api-url="url" :per-page="10">
    <!-- #item 슬롯: 구조분해로 body, username, likes를 꺼내 렌더링 -->
    <template #item="{ body, username, likes }">
      <div class="item">
        <p>{{ body }}</p>
        <p class="meta">by {{ username }} | {{ likes }} likes</p>
      </div>
    </template>
    <!-- #more 슬롯: load 함수를 loadMore로 별칭 후 버튼에 연결 -->
    <template #more="{ load: loadMore }">
      <v-btn @click="loadMore">More...</v-btn>
    </template>
  </FancyList>
</template>

<script setup>
import FancyList from "@/components/FancyList.vue"
</script>
```
- `v-bind="item"` (자식): 객체의 모든 속성을 개별 슬롯 prop으로 한 번에 전달 (shorthand spread)
- `#item="{ body, username, likes }"` (부모): 구조분해 할당으로 필요한 값만 추출

### 2.10 ToDo Item 상세 페이지 (`item.[itemid].vue`)
- **주요 기능**: 파일 기반 동적 라우팅(`[itemid]` 파라미터)을 사용하여 특정 ToDo 항목 상세 정보를 API에서 조회합니다.

```vue
<template>
  <v-container>
    <v-card class="pa-4 pt-7" max-width="600">
      <v-card-item>
        <v-card-title>{{ item.title }}</v-card-title>
        <v-card-subtitle class="pt-2">
          <v-icon icon="mdi-alarm"></v-icon>
          등록 {{ item.created_at }} # {{ item.remote_ip }}
        </v-card-subtitle>
        <v-card-subtitle class="pt-2 text-pink">
          <v-icon icon="mdi-alarm"></v-icon>
          만료 {{ item.due_date }}
        </v-card-subtitle>
        <v-card-text class="text-h6">{{ item.content }}</v-card-text>
      </v-card-item>
      <v-divider class="mx-4 mb-1"></v-divider>
      <v-card-subtitle>{{ item.description }}</v-card-subtitle>
      <v-card-actions>
        <v-btn text="Back" block border color="orange" to="/"></v-btn>
      </v-card-actions>
    </v-card>
  </v-container>
</template>

<script setup>
  import { ref, onMounted } from 'vue'
  import { useRoute } from 'vue-router'
  import axios from 'axios'

  const route = useRoute()
  const itemid = route.params.itemid    // URL의 [itemid] 파라미터 추출
  const item = ref({})

  const load = () => {
    axios.get(`http://syntaxwiki.com:9993/item/${itemid}`).then((res) => {
      item.value = res.data
    })
  }
  onMounted(() => { load() })
</script>
```
- `item.[itemid].vue` 파일 이름 규칙 → `unplugin-vue-router`가 `/item/:itemid` 경로로 자동 매핑
- `useRoute().params.itemid` → 현재 URL에서 `:itemid` 동적 파라미터 값 추출

### 3.2 앱 헤더 컴포넌트 (`AppHeader.vue`)

```vue
<template>

    <!-- v-slot:image Named Slot으로 app-bar 배경 이미지 커스터마이징 -->

```
- `<v-app-bar>` 컴포넌트가 `image` Named Slot을 내부적으로 정의해두고 있으며, 부모가 `v-slot:image`로 커스텀 `<v-img>`를 주입하여 그라디언트 효과를 덮어씌움

### 4.1 i18n 국제화 설정 (`plugins/i18n.ts`) — todolist
```typescript
import { createI18n } from 'vue-i18n'

const messages = {
  en: { message: { hello: 'hello world' } },
  ja: { message: { hello: 'こんにちは、世界' } },

export default createI18n({

  fallbackLocale: 'en',
  messages,
})
```

- `legacy: false`: `useI18n()` Composable API 사용 가능 모드 (Vue 3 권장 방식)

- `typed-router.d.ts`: `unplugin-vue-router`가 `pages/` 폴더를 분석하여 자동 생성하는 라우트 타입 정의 파일 (모든 URL 경로에 TypeScript 타입 부여)

## 5. TypeScript 및 Vuetify 3 UI 연동 정리

- **Vuetify 3 Transition 연동 컴포넌트**:
  - `<v-hover v-slot="{ isHovering, props }">`: Vuetify 자체 Scoped Slot 기반 호버 상태 제공 컴포넌트
  - `<v-overlay :model-value="isHovering">`: 호버 상태와 바인딩하여 동적 오버레이 표시
  - `<v-dialog>`: 모달 다이얼로그, `activator` 슬롯으로 트리거 요소 지정
  - `<v-confirm-edit>` + `<v-date-picker>`: 날짜 선택 확인/취소 플로우 구현

- **GSAP + Vue 3 통합 패턴**:
  - `:css="false"` + JS 훅: CSS 클래스 기반 전환 비활성화 후 GSAP이 직접 DOM 제어
  - `ref()` 로 DOM 참조 획득 후 `gsap.from()` / `gsap.timeline()`에 전달
  - `$el` 접근: Vuetify 컴포넌트 래퍼의 실제 DOM 요소 접근 시 사용

- **TypeScript 타입 안전성**:
  - `import type { App } from 'vue'`: 타입 전용 import로 번들 크기 최적화
  - `typed-router.d.ts`: 라우트 경로 문자열에 타입 부여로 오타 방지
  - `components.d.ts`: 자동 import 컴포넌트 타입 추론 지원

## 6. 💡 핵심 문법 정리 표 (Key Takeaways)

| 개념 | 주요 기능 및 문법 예시 | 핵심 특징 |
|------|------------------------|-----------|
| **Vue Transition** | `<transition name="fade">`, `.fade-enter-active` | 단일 요소 진입/퇴장 CSS 클래스 자동 부여 |
| **TransitionGroup** | `<transition-group tag="ul">`, `.list-move` | 리스트 항목 각각 애니메이션 + FLIP 이동 지원 |
| **Transition Mode** | `mode="out-in"` | 퇴장 완료 후 진입 시작으로 겹침 없는 전환 |
| **JS Transition Hook** | `@enter="fn"`, `:css="false"`, `done()` 콜백 | CSS 없이 JS로 애니메이션 전적 제어 |
| **GSAP 연동** | `gsap.from()`, `gsap.fromTo()`, `gsap.timeline()` | 고급 이징·타임라인 순차 애니메이션 |
| **Named Scoped Slot** | `<slot name="item" v-bind="item">`, `#item="{ body }"` | 자식이 데이터와 함수를 부모 슬롯으로 노출 |
| **동적 파라미터 라우팅** | `item.[itemid].vue` → `/item/:itemid`, `useRoute().params.itemid` | 파일명 규칙 기반 자동 동적 경로 매핑 |
| **v-app-bar Named Slot** | `<template v-slot:image>` | Vuetify 내장 컴포넌트 슬롯으로 내부 렌더링 커스터마이징 |
| **Pinia** | `createPinia()` → `app.use(createPinia())` | Vue 3 공식 전역 상태 관리 라이브러리 |
| **defineModel()** | `const model = defineModel()` | Vue 3.4+ 양방향 바인딩 단축 문법 (props+emit 통합) |
