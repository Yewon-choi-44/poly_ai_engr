# 📝 2026-09-23 (수) 실습 정리: CSS Flexbox 속성 인터랙티브 테스터 (`flexblog`)

본 문서는 `flexblog` 프로젝트에서 진행한 **CSS Flexbox 컨테이너/아이템 속성 실습**을 정리한 아카이브 문서입니다.
각 페이지는 노란 컨테이너(`.meal-css-tester-container`) 안에 초록 아이템(`.meal-css-tester-item`) 3~5개를 배치하고, Vuetify `<v-btn-toggle>`로 속성값을 바꾸면 `:style` 바인딩을 통해 레이아웃이 즉시 바뀌는 구조로 되어 있습니다.

## 1. 실행 환경 및 진입 구조

- **프로젝트**: `flexblog/` (Vite + Vue 3 + Vuetify + TypeScript + Pinia + vue-i18n + unplugin-vue-router, 2026-09-16 생성)
- **진입 구조**: `main.ts` → `plugins/index.ts`(Vuetify·Pinia·i18n·Router 등록) → `App.vue`(`<v-app><v-main><router-view/></v-main></v-app>`) — 2026-09-16 문서와 동일
- **레이아웃**: `router/index.ts`는 `setupLayouts(routes)`를 쓰지만, 레이아웃 폴더가 `src/layouts_/`(밑줄)로 이름이 바뀌어 있어 레이아웃 플러그인이 인식하지 않습니다 → Flex 실습 페이지들은 헤더 없이 단독 렌더링됩니다.

### 1.1 파일 기반 라우팅 경로 매핑 (`typed-router.d.ts` 기준)

`unplugin-vue-router`는 파일명 대소문자를 그대로 URL에 반영합니다.

| 파일 경로 | URL 경로 | 실습 주제 |
|-----------|----------|-----------|
| `pages/index.vue` | `/` | 홈 (`Home.vue` 렌더링) |
| `pages/FlexDisplay.vue` | `/FlexDisplay` | `display: block` ↔ `flex` |
| `pages/FlexDirection.vue` | `/FlexDirection` | 주축 방향 |
| `pages/FlexWrap.vue` | `/FlexWrap` | 줄바꿈 |
| `pages/FlexJustifyContent.vue` | `/FlexJustifyContent` | 주축 정렬 |
| `pages/FlexAlignContent.vue` | `/FlexAlignContent` | 여러 줄(교차축) 정렬 |
| `pages/FlexAlignItems.vue` | `/FlexAlignItems` | 한 줄 안의 교차축 정렬 |
| `pages/FlexGrow.vue` | `/FlexGrow` | 남는 공간 분배 비율 |
| `pages/FlexBasis.vue` | `/FlexBasis` | 아이템 기본 크기 |
| `pages/FlexShrink.vue` | `/FlexShrink` | 부족한 공간 축소 비율 |

### 1.2 라우터 (`router/index.ts`)
```typescript
/**
 * router/index.ts
 *
 * Automatic routes for ./src/pages/*.vue
 */

// Composables
import { setupLayouts } from 'virtual:generated-layouts'
import { createRouter, createWebHistory } from 'vue-router'
import { routes } from 'vue-router/auto-routes'

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: setupLayouts(routes),
})

export default router
```

## 2. 공통 스타일 (`assets/custom.css`)

모든 Flex 페이지가 `<style>` 안에서 `@import '@/assets/custom.css'`로 불러와 쓰는 공통 스타일입니다.

```css
.meal-css-tester-item {
    margin: 3px;
    padding: 2px;
    border: 3px solid currentColor;
    border-radius: 3px;
    font-weight: bold;
    background: #26ab1c;
    transition: 0.4s;
}

.meal-css-tester-container {
    border: 3px solid currentColor;
    border-radius: 5px;
    font-size: 1.2em;
    line-height: 1.4;
    background: #ffe300;
    transition: 0.5s;
}

.baseline {
    height: 1px;
    background-color: red;
    width: 80vw;
    position: absolute;
    top: 61px;
    left: 0;
}

.v-line {
    background-image: linear-gradient(to right, black 1px, transparent 1px);
    background-repeat: repeat;
    background-size: 20px 100%; /* 10px 간격*/
    flex-grow: 1;
}
```
- `.meal-css-tester-container`(노랑) / `.meal-css-tester-item`(초록): 컨테이너와 아이템을 색으로 구분
- `transition: 0.4s / 0.5s`: 속성값을 바꿀 때 레이아웃 변화가 애니메이션으로 보이도록 함
- `.baseline`: `align-items: baseline` 확인용 빨간 가로 가이드선 (`position: absolute`)
- `.v-line`: `linear-gradient`로 20px 간격 세로 눈금을 그려 아이템 폭을 눈으로 비교 (`FlexShrink.vue`에서 사용)

## 3. 개별 실습 페이지 컴포넌트 (*.vue)

### 3.1 `FlexDisplay.vue` — display: block vs flex
```vue
<template>
    <div class="meal-css-tester-container ma-4" :style="{ display: boxDisplay }">
        <div class = "meal-css-tester-item">AAA</div>
        <div class = "meal-css-tester-item">BBBBBBB</div>
        <div class = "meal-css-tester-item">CCCCC</div>
    </div>

    <div class="ma-4">display: {{ boxDisplay }}</div>
    <v-btn-toggle
        variant = "outlined"
        divided class = "ma-4"
        v-model = "boxDisplay">
        <v-btn text="block" value="block"></v-btn>
        <v-btn text="flex" value="flex"></v-btn>
    </v-btn-toggle>
</template>

<script setup>
    import { ref } from 'vue'
    const boxDisplay = ref("block")
</script>

<style lang="css">
    @import '@/assets/custom.css';
</style>
```
- **동작 원리**: `v-btn-toggle`의 `v-model="boxDisplay"`가 선택된 버튼의 `value`를 `ref`에 넣고, `:style="{ display: boxDisplay }"`가 그 값을 인라인 스타일로 반영합니다.
- `block`: 자식 `div`가 세로로 쌓이고 각각 가로 전체를 차지 / `flex`: 자식이 **flex item**이 되어 가로(주축) 한 줄로 내용 폭만큼 배치됩니다.

### 3.2 `FlexDirection.vue` — flex-direction
```vue
<template>
    <div class="meal-css-tester-container ma-4 d-flex" :style="{ flexDirection }">
        <div class="meal-css-tester-item">AAA</div>
        <div class="meal-css-tester-item">BBBBBBB</div>
        <div class="meal-css-tester-item">CCCC</div>
    </div>
    <div class="ma-4">flex-direction: {{  boxDirection }}</div>
    <v-btn-toggle variant="outlined" divided class="ma-4" v-model="flexDirection">
        <v-btn text="row" value="row"></v-btn>
        <v-btn text="row-reverse" value="row-reverse"></v-btn>
        <v-btn text="column-reverse" value="column-reverse"></v-btn>
    </v-btn-toggle>
</template>

<script setup>
    import { ref } from 'vue'
    const flexDirection = ref("row")
</script>

<style lang="scss" scoped>
    @import '@/assets/custom.css';
</style>
```
- `d-flex`: Vuetify 유틸리티 클래스 (`display: flex !important`)
- `:style="{ flexDirection }"`: **객체 속성 축약 표기** — `{ flexDirection: flexDirection }`과 같음. 변수명을 CSS 속성의 camelCase 이름과 똑같이 지으면 이렇게 쓸 수 있습니다.
- `row`(기본, 왼→오) / `row-reverse`(오→왼) / `column-reverse`(아래→위). 주축이 바뀌면 이후의 `justify-content`, `align-items`가 다루는 방향도 함께 바뀝니다.

### 3.3 `FlexWrap.vue` — flex-wrap
```vue
<template>
    <div class="meal-css-tester-container ma-4 d-flex" :style="{flexWrap, width: '13rem'}">
        <div class="meal-css-tester-item">AAA</div>
        <div class="meal-css-tester-item">BBBBBBB</div>
        <div class="meal-css-tester-item">CCCC</div>
    </div>
    <div class="ma-4">flex-wrap: {{ flexWrap }}</div>
    <v-btn-toggle
        variant="outlined" divided class="ma-4" v-model="flexWrap">
        <v-btn text="nowrap" value="nowrap"></v-btn>
        <v-btn text="wrap" value="wrap"></v-btn>
        <v-btn text="wrap-reverse" value="wrap-reverse"></v-btn>
    </v-btn-toggle>
</template>

<script setup>
    import { ref } from 'vue'
    const flexWrap = ref("nowrap")
</script>

<style lang="scss" scoped>
    @import '@/assets/custom.css';
</style>
```
- 컨테이너 폭을 `13rem`으로 좁혀 아이템이 한 줄에 다 들어가지 않게 만든 뒤 비교합니다.
- `nowrap`: 넘쳐도 한 줄 유지(아이템 축소/오버플로) / `wrap`: 다음 줄로 넘김 / `wrap-reverse`: 줄 쌓는 방향을 반대(아래→위)로.
- `:style`에 **반응형 값(`flexWrap`)과 고정값(`width: '13rem'`)을 한 객체에 섞어서** 쓸 수 있습니다.

### 3.4 `FlexJustifyContent.vue` — justify-content
```vue
<template>
    <div class="meal-css-tester-container ma-4 d-flex" :style="{ justifyContent }">
        <div class="meal-css-tester-item">AAA</div>
        <div class="meal-css-tester-item">BBBBBBB</div>
        <div class="meal-css-tester-item">CCCC</div>
    </div>
    <div class="ma-4">justify-content: {{ justifyContent }}</div>
    <v-btn-toggle variant="outlined" divided class="ma-4" v-model="justifyContent">
        <template v-for="option in justifyOptions">
            <v-btn :text="option" :value="option"></v-btn>
        </template>
    </v-btn-toggle>
</template>

<script setup>
    import { ref } from 'vue'
    const justifyContent = ref("flex-start")
    const justifyOptions = ref([
        "flex-start",
        "flex-end",
        "center",
        "space-between",
        "space-around",
        "space-evenly"
    ])  
</script>

<style lang="scss" scoped>
    @import '@/assets/custom.css';
</style>
```
- 이 페이지부터 버튼을 하드코딩하지 않고 **옵션 배열 + `<template v-for>`** 로 생성합니다.
- `space-between`: 양 끝 붙이고 사이 균등 / `space-around`: 각 아이템 양옆에 같은 여백(끝 여백은 사이 여백의 절반) / `space-evenly`: 끝 포함 모든 간격 동일.

### 3.5 `FlexAlignContent.vue` — align-content
```vue
<template>
    <div class="meal-css-tester-container ma-4 d-flex" :style="{ alignContent, flexWrap: 'wrap', height: '15rem' }">
        <div class="meal-css-tester-item">AAA</div>
        <div class="meal-css-tester-item">BBBBBBBBBBBB</div>
        <div class="meal-css-tester-item">CCCC</div>
        <div class="meal-css-tester-item">DDDDDDDDDDDDDDDDDDD</div>
        <div class="meal-css-tester-item">FFFFFFFFFFFFFFFFFFFFFFFFFFFFF</div>
    </div>
    <div class="ma-4">align-content: {{  alignContent }}</div>
    <v-btn-toggle variant="outlined" divided class="ma-4" :style="{flexWrap: 'wrap', height: '100px'}" v-model="alignContent">
        <template v-for="option in options">
            <v-btn :text="option" :value="option"></v-btn>
        </template>
    </v-btn-toggle>
</template>

<script setup>
    import { ref } from 'vue'
    const alignContent = ref("stretch")
    const options = ref([
        "stretch",
        "flex-start",
        "flex-end",
        "center",
        "space-between",
        "space-around",
        "space-evenly"
    ])
</script>

<style lang="scss" scoped>
    @import '@/assets/custom.css';
</style>
```
- `align-content`는 **줄이 2개 이상일 때만** 의미가 있으므로 `flexWrap: 'wrap'` + 고정 높이 `15rem`을 함께 줍니다.
- 줄(line) 묶음 전체를 교차축 방향으로 어떻게 배치할지를 정합니다 (`align-items`는 한 줄 안의 아이템 정렬).
- 버튼이 7개라 토글 자체에도 `flexWrap: 'wrap'`을 줘서 버튼 그룹이 줄바꿈되도록 했습니다.

### 3.6 `FlexAlignItems.vue` — align-items (+ baseline 가이드선)
```vue
<template>
    <div class="meal-css-tester-container ma-4 d-flex position-relative" style="justify-content: center;" :style="{ alignItems, height: '15rem' }">
        <div class="meal-css-tester-item" style="font-size: 30px;">AAA</div>    
        <div class="meal-css-tester-item" style="font-size: 14px;">BBBBBBB</div>    
        <div class="meal-css-tester-item" style="font-size: 50px; width: 150px;">CCCC</div>    
        <div class="meal-css-tester-item" style="font-size: 40px; width: 150px;">gggg</div>
        <div v-if="alignItems == 'baseline'" class="baseline"></div> 
    </div>

    <div class="ma-4">align-items: {{ alignItems }}</div>
    <v-btn-toggle variant="outlined" divided class="ma-4" v-model="alignItems">
        <template v-for="option in options">
            <v-btn :text="option" :value="option"></v-btn>
        </template>
    </v-btn-toggle>
</template>

<script setup>
    import { ref } from 'vue'
    const alignItems = ref("stretch")
    const options = ref([
        "stretch",
        "flex-start",
        "flex-end",
        "center",
        "baseline"
    ])
</script>

<style lang="scss" scoped>
    @import '@/assets/custom.css';
</style>
```
- 아이템마다 `font-size`를 다르게(14~50px) 줘서 `baseline` 정렬 효과(글자 밑선 맞춤)가 잘 보이도록 했습니다.
- **정적 `style`과 동적 `:style`을 같은 요소에 동시에 사용** — Vue가 두 값을 병합합니다.
- `v-if="alignItems == 'baseline'"`: baseline이 선택됐을 때만 빨간 가이드선(`.baseline`, `position: absolute`)을 표시. 부모에 `position-relative`(Vuetify 유틸)를 줘서 기준 위치를 컨테이너로 잡습니다.

### 3.7 `FlexGrow.vue` — flex-grow
```vue
<template>
    <div class="meal-css-tester-container ma-4 d-flex">
        <div class="meal-css-tester-item" :style="{ flexGrow: flexGrow1 }">AAA</div>
        <div class="meal-css-tester-item" :style="{ flexGrow: flexGrow2 }">BBBBBBB</div>
        <div class="meal-css-tester-item" :style="{ flexGrow: flexGrow3 }">CCCC</div>
    </div>

    <div class="ma-4">1. flex-grow: {{ flexGrow1 }}</div>
    <v-btn-toggle variant="outlined" divided class="ma-4" v-model="flexGrow1">
        <template v-for="option in growOptions">
            <v-btn :text="option" :value="option"></v-btn>
        </template>
    </v-btn-toggle>

    <div class="ma-4">2. flex-grow: {{ flexGrow2 }}</div>
    <v-btn-toggle variant="outlined" divided class="ma-4" v-model="flexGrow2">
        <template v-for="option in growOptions">
            <v-btn :text="option" :value="option"></v-btn>
        </template>
    </v-btn-toggle>

    <div class="ma-4">3. flex-grow: {{ flexGrow3 }}</div>
    <v-btn-toggle variant="outlined" divided class="ma-4" v-model="flexGrow3">
        <template v-for="option in growOptions">
            <v-btn :text="option" :value="option"></v-btn>
        </template>
    </v-btn-toggle>
</template>

<script setup>
    import { ref } from 'vue'

    const flexGrow1 = ref("0")
    const flexGrow2 = ref("0")
    const flexGrow3 = ref("0")
    const growOptions = ref([
        "0",
        "1",
        "2",
        "3"
    ])
</script>

<style lang="scss" scoped>
    @import "@/assets/custom.css"
</style>
```
- 여기서부터는 **컨테이너가 아닌 개별 아이템 속성** 실습입니다. 아이템 3개에 각각 독립 `ref`와 토글을 연결했습니다.
- `flex-grow`: 컨테이너에 **남는 공간**을 grow 값의 비율로 나눠 가짐. 모두 0이면 내용 폭 그대로, `1:1:1`이면 남는 공간을 3등분해 더함, `1:2:0`이면 첫째 1/3, 둘째 2/3를 가져갑니다(아이템 전체 폭이 1:2가 되는 것은 아님).

### 3.8 `FlexBasis.vue` — flex-basis
```vue
<template>
    <div class="meal-css-tester-container ma-4 d-flex">
        <div class="meal-css-tester-item" :style="{ flexBasis, flexGrow }">AAA</div>
        <div class="meal-css-tester-item" :style="{ flexBasis, flexGrow }">BBBBBBBBB</div>
        <div class="meal-css-tester-item" :style="{ flexBasis, flexGrow }">CCCC</div>
    </div>
    <div class="ma-4">flex-basis: {{ flexBasis }}</div>
    <v-btn-toggle variant="outlined" divided class="ma-4" v-model="flexBasis">
        <template v-for="option in basisOptions">
            <v-btn :text="option" :value="option"></v-btn>
        </template>
    </v-btn-toggle>

    <div class="ma-4">flex-grow: {{  flexGrow  }}</div>
    <v-btn-toggle variant="outlined" divided class="ma-4" v-model="flexGrow">
        <template v-for="option in growOptions">
            <v-btn :text="option" :value="option"></v-btn>
        </template>
    </v-btn-toggle>
</template>

<script setup>
    import { ref } from 'vue'
    const flexBasis = ref("auto")
    const basisOptions = ref([
        "auto",
        "50%",
        "200px",
        "content"
    ])

    const flexGrow = ref("0")
    const growOptions = ref([
        "0",
        "1"
    ])
</script>

<style lang="scss" scoped>
    @import '@/assets/custom.css';
</style>
```
- `flex-basis`: grow/shrink가 적용되기 **전의 기본 크기**. `auto`(=width 또는 내용 크기) / `50%`(컨테이너 기준) / `200px` / `content`(내용 크기).
- `flex-grow`를 함께 토글해서, 기본 크기를 정한 뒤 남는 공간이 어떻게 더해지는지 비교합니다. 세 아이템이 같은 `flexBasis`, `flexGrow` 값을 공유합니다.

### 3.9 `FlexShrink.vue` — flex-shrink 축소량 계산기
```vue
<template>
    <div class="meal-css-tester-container ma-4 d-flex" ref="flexContainer">
        <div class="meal-css-tester-item d-flex" :style="{ flexBasis: `${width1}px`, flexShrink: flexShrink1 }">
            A {{ shrinkw }} x ({{ width1 }} x {{ flexShrink1 }} / {{ basisWeightSum }}) 
            = {{ (shrinkw * width1 * flexShrink1 / basisWeightSum).toFixed(0) }}
            <div class="v-line"></div>
        </div>
        <div class="meal-css-tester-item d-flex" :style="{ flexBasis: `${width2}px`, flexShrink: flexShrink2 }">

<script setup>
    import { computed, onBeforeUnmount, onMounted, ref } from 'vue'
    const flexContainer = ref(null)
    const containerWidth = ref(0)
    const width1 = ref(200)
    const width2 = ref(300)
    const width3 = ref(300)
    const flexShrink1 = ref(1)
    const flexShrink2 = ref(1)
    const flexShrink3 = ref(1)
    const shrinkw = ref(0)
    const basisWeightSum = computed(() => {
        return width1.value * flexShrink1.value + width2.value * flexShrink2.value + width3.value * flexShrink3.value
    })
    const updateDivWidth = () => {
        console.log(flexContainer.value)
        containerWidth.value = flexContainer.value.clientWidth
        shrinkw.value = containerWidth.value - width1.value - width2.value - width3.value
    };

    onMounted(() => {
        updateDivWidth();
        window.addEventListener('resize', updateDivWidth);
    })

    onBeforeUnmount(() => {
        window.removeEventListener('resize', updateDivWidth);
    })

    const options = ref([
        0,
        1,
        2,
        3
    ])
</script>

<style lang="scss scoped">
    @import "@/assets/custom.css";
</style>
```

- **동작 원리 (flex-shrink 축소 공식)**: 아이템 기본 크기 합(200+300+300=800px)이 컨테이너보다 클 때, 부족한 폭(`shrinkw`, 음수)을 **`basis × shrink` 가중치 비율로** 나눠서 각 아이템에서 뺍니다.
  - 아이템 i의 축소량 = `부족분 × (basis_i × shrink_i) / Σ(basis × shrink)`
  - 화면에 이 공식을 그대로 템플릿 보간(`{{ }}`)으로 출력해 실제 축소 폭을 눈으로 검증합니다.
- `basisWeightSum`: `computed`로 가중치 합을 계산 → shrink 값을 바꾸면 자동 재계산
- **Template Ref**: `ref="flexContainer"` + `const flexContainer = ref(null)` → 마운트 후 실제 DOM의 `clientWidth`를 읽음
- **라이프사이클 훅**: `onMounted`에서 `window.resize` 이벤트 리스너 등록 → 창 크기를 바꿀 때마다 컨테이너 폭 재측정, `onBeforeUnmount`에서 리스너 제거(메모리 누수 방지)
- **템플릿 리터럴 바인딩**: `` :style="{ flexBasis: `${width1}px` }" ``, `` :text="`${option}`" `` (숫자 옵션을 문자열로 변환해 버튼 텍스트로 사용)
- 아이템 안의 `.v-line` 눈금(20px 간격)으로 줄어든 폭을 시각적으로 비교

코드는 수정하지 않았으며, 다음 실습 때 확인할 만한 부분만 기록합니다.

| 파일 | 내용 |
|---|---|
| `FlexDirection.vue` | 템플릿이 `{{ boxDirection }}`을 출력하지만 스크립트에는 `flexDirection`만 선언되어 있어 현재 값 표시가 비어 보입니다. 또 `column` 옵션 버튼이 빠져 있습니다(`row`, `row-reverse`, `column-reverse`만 있음). |

## 7. 💡 핵심 문법 정리 표 (Key Takeaways)

| 개념 | 주요 기능 및 문법 예시 | 핵심 특징 |
|------|------------------------|-----------|
| **display: flex** | `:style="{ display: 'flex' }"`, `class="d-flex"` | 자식이 flex item이 되어 주축 방향으로 배치 |
| **flex-direction** | `row` / `row-reverse` / `column` / `column-reverse` | 주축 방향 결정 → 이후 정렬 속성의 기준축이 바뀜 |
| **flex-wrap** | `nowrap` / `wrap` / `wrap-reverse` | 컨테이너 폭이 부족할 때 줄바꿈 여부 |
| **justify-content** | `flex-start`, `center`, `space-between`, `space-around`, `space-evenly` | **주축** 방향 아이템 정렬·간격 |
| **align-items** | `stretch`, `flex-start`, `flex-end`, `center`, `baseline` | 한 줄 안에서 **교차축** 정렬 |
| **align-content** | `stretch`, `space-between` 등 (+ `flex-wrap: wrap` 필요) | **여러 줄 묶음** 전체의 교차축 배치 |
| **flex-grow** | `flexGrow: 0 ~ 3` | 남는 공간을 비율대로 분배 |
| **flex-basis** | `auto`, `50%`, `200px`, `content` | grow/shrink 적용 전 기본 크기 |
| **flex-shrink** | 축소량 = 부족분 × (basis×shrink) / Σ(basis×shrink) | 부족한 공간을 basis 가중 비율로 줄임 |
| **:style 객체 바인딩** | `:style="{ flexDirection }"` (속성 축약) | camelCase 키로 CSS 속성 바인딩, 정적 `style`과 병합됨 |
| **v-for로 버튼 생성** | `<template v-for="option in options"><v-btn :value="option"/></template>` | 옵션 배열 하나로 토글 버튼 자동 생성 |
| **Template Ref + resize** | `ref="flexContainer"`, `onMounted` / `onBeforeUnmount`에서 리스너 등록·해제 | 실제 DOM 크기 측정 및 반응형 갱신 |
| **computed** | `basisWeightSum = computed(() => ...)` | 의존 ref가 바뀌면 자동 재계산 |
