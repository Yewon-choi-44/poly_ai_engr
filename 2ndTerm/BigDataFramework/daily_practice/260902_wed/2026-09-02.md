## 1️⃣ [Part 1] 컴포넌트 기본 & Props 데이터 전달

### 실습 1: Props 기본 정의 및 전달 (BlogPost.vue ↔ BlogPage.vue)
- **접속 URL**: `/blog-page`
- **핵심 동작 원리**:
  - `defineProps(['title'])`: 컴포넌트 외부(부모)로부터 전달받을 속성을 선언하는 컴파일러 매크로 함수입니다. 별도의 import 없이 `<script setup>` 내에서 사용 가능합니다.
  - 부모 컴포넌트는 HTML 어트리뷰트 방식으로 자식 컴포넌트에 데이터를 전달합니다.

```vue
<!-- exam0902/src/components/BlogPost.vue -->
<script setup>
    defineProps(['title']) // import 안해도 사용 가능 매크로
</script>

<template>
    <v-container>
        <v-row>
            <v-col>
                블로그 제목
            </v-col>
            <v-col>
                {{ title }}
            </v-col>
        </v-row>
    </v-container>
</template>
```

```vue
<!-- exam0902/src/pages/BlogPage.vue -->
<script setup>
    import BlogPost from '@/components/BlogPost.vue';
</script>

<template>
    <BlogPost title="Vue와 함께한 나의 여행"/>
    <BlogPost title="Vue로 블로깅하기"/>
    <BlogPost title="Vue가 재미있는 이유"/>
</template>
```

### 실습 2: v-for 목록 렌더링과 Props 연동 (BlogPageVFor.vue)
- **접속 URL**: `/blog-page-v-for`
- **핵심 동작 원리**:
  - 반응형 배열(`posts`)을 `v-for` 디렉티브로 순회하면서 각 객체의 프로퍼티를 자식 컴포넌트의 prop(`:title="post.title"`)으로 동적 바인딩합니다.
  - 고유한 `:key`를 지정하여 가상 DOM 렌더링 성능을 최적화합니다.

```vue
<!-- exam0902/src/pages/BlogPageVFor.vue -->
<template>
    <BlogPost
        v-for="post in posts"
        :key="post.id"
        :title="post.title"
    />
</template>

<script setup>
    import BlogPost from '@/components/BlogPost.vue';
    import { ref } from 'vue'

    const posts = ref([
        { id: 1, title: "Vue와 함께한 나의 여행"},
        { id: 2, title: "Vue로 블로깅하기"},
        { id: 3, title: "Vue가 재미있는 이유"}

</script>
```

## 2️⃣ [Part 2] 컴포넌트 이벤트 & Emit (자식 ➔ 부모 통신)

### 실습 3: 기본 Emit 이벤트 발신 및 처리 (BlogPostEmit.vue ↔ BlohPageEmit.vue)
- **접속 URL**: `/bloh-page-emit`
- **핵심 동작 원리**:
  - `defineEmits(['enlarge-text'])`: 자식 컴포넌트가 발생시킬 수 있는 커스텀 이벤트를 선언합니다.
  - 자식 컴포넌트 템플릿에서는 `$emit('이벤트명')`을 직접 호출하거나, 스크립트에서 `emit('이벤트명')` 함수를 실행합니다.
  - 부모 컴포넌트는 `@enlarge-text="postFontSize += 0.1"`와 같이 이벤트 리스너를 바인딩하여 부모의 반응형 상태를 변경합니다.

```vue
<!-- exam0902/src/components/BlogPostEmit.vue -->
<script setup>
    defineProps(['title'])
    const emit = defineEmits(['enlarge-text'])

    const enlarge = () => {
        // $emit('enlarge-text')
        emit('enlarge-text')
    }
</script>

<template>
    <div class = "blog-post">
        <h4>{{ title }}</h4>
        <v-btn @click="$emit('enlarge-text')">텍스트 크게</v-btn>
        <v-btn @click="enlarge">텍스트 크게</v-btn>
    </div>
</template>

<style scoped>
    .blog-post {
        margin: 10px;
        border: 1px solid;
        padding: 5px;
    }
</style>
```

```vue
<!-- exam0902/src/pages/BlohPageEmit.vue -->
<template>
    <div :style="{ fontSize: postFontSize + 'em'}">
        <BlogPostEmit
            v-for="post in posts"
            :key="post.id"
            :title="post.title"
            @enlarge-text="postFontSize += 0.1" />
    </div>
</template>

<script setup>
    import { ref } from 'vue'
    import BlogPostEmit from '@/components/BlogPostEmit.vue'

    const postFontSize = ref(1)
    const posts = ref([
        { id: 1, title: 'Vue와 함께한 나의 여행'},
        { id: 2, title: 'Vue로 블로깅하기'},
        { id: 3, title: 'Vue가 재미있는 이유'},
    ])
</script>
```

### 실습 4: 개별 폰트 상태 제어 테스트 (BlogPageEmitStandalone.vue)
- **접속 URL**: `/blog-page-emit-standalone`
- **핵심 동작 원리**: 포스트별로 독립적인 폰트 크기를 유지하기 위해 객체 형태의 ref를 사용하는 패턴 테스트.

```vue
<!-- exam0902/src/pages/BlogPageEmitStandalone.vue -->
<template>
    <div :style="{ fontSize: postFontSize + 'em'}">
        <BlogPostEmit
            v-for="post in posts"
            :key="post.id"
            :title="post.title"
            @enlarge-text="postFontSize += 0.1" />
    </div>
</template>

<script setup>
    import { ref } from 'vue'
    import BlogPostEmit from '@/components/BlogPostEmit.vue'

    const posts = ref([
        { id: 1, title: 'Vue와 함께한 나의 여행'},
        { id: 2, title: 'Vue로 블로깅하기'},
        { id: 3, title: 'Vue가 재미있는 이유'},
    ])

    const postFontSize = ref({})
    for (const post of posts.value) {
        postFontSize.value[post.id] = 1
    }
</script>
```

## 3️⃣ [Part 3] 컴포넌트 양방향 바인딩 (v-model & defineModel)

### 실습 5: Vue 3.4+ defineModel() 기본 (ChildComp.vue ↔ ParentComp.vue)
- **접속 URL**: `/parent-comp`
- **핵심 동작 원리**:
  - Vue 3.4에서 도입된 `defineModel()` 매크로는 부모의 `v-model`과 자식 컴포넌트의 내부 ref를 자동으로 양방향 동기화해 줍니다.
  - 보일러플레이트 코드(`props: ['modelValue']` + `emit('update:modelValue')`) 없이 단 한 줄로 자식 컴포넌트의 폼 입력을 부모와 동기화할 수 있습니다.

```vue
<!-- exam0902/src/components/ChildComp.vue -->
<template>
    <v-container class="border-md border-info">
        <v-row>
            <div class="ma-2">
                부모 바인딩 v-model은: {{ model }}
            </div>
        </v-row>
        <v-row>
            <input v-model="model" class="ma-2 border-thin pa-2"/>
        </v-row>
    </v-container>
</template>

<script setup>
    const model = defineModel()
</script>
```

```vue
<!-- exam0902/src/pages/ParentComp.vue -->
<template>
    <v-container>
        Parent Model: {{ textModel }}
        <hr>
        <ChildComp v-model="textModel" class="my-3" />
    </v-container>
</template>

<script setup>
    import { ref } from 'vue'
    import ChildComp from '@/components/ChildComp.vue'
    const textModel = ref('init')
</script>
```

### 실습 6: 전통적 props + emit 기반 양방향 바인딩 (ChildCompIn.vue / ChildCompIn2.vue ↔ ParentCompIn.vue)
- **접속 URL**: `/parent-comp-in`, `/parent-comp-in2`
- **핵심 동작 원리**:
  - `defineModel` 도입 이전의 표준적인 `v-model` 동작 원리:
    1. 부모가 자식에게 `modelValue`라는 이름의 prop으로 값을 전달 (`:value="props.modelValue"`)
    2. 자식이 값 변경 시 `update:modelValue` 이벤트를 payload와 함께 발생 (`emit('update:modelValue', $event.target.value)`)
    3. 부모 컴포넌트가 해당 이벤트를 받아 내부 상태를 갱신

```vue
<!-- exam0902/src/components/ChildCompIn.vue & ChildCompIn2.vue -->
<template>
    <v-container class="border-md border-info">
        <v-row>
            <div class="ma-2">
                부모 바인딩 v-model은: {{ modelValue }}
            </div>
        </v-row>
        <v-row>
            <input
                :value="props.modelValue"
                @input="emit('update:modelValue', $event.target.value)"
                class="ma-2 border-thin pa-2"
            />
        </v-row>
    </v-container>
</template>

<script setup>
    const props = defineProps(['modelValue'])
    const emit = defineEmits(['update:modelValue'])
</script>
```

```vue
<!-- exam0902/src/pages/ParentCompIn.vue -->
<template>
    <v-container>
        Parent Model: {{ textModel }}
        <hr>
        <ChildCompIn v-model="textModel" class="my-3" />
    </v-container>
</template>

<script setup>
    import { ref } from 'vue'
    import ChildCompIn from '@/components/ChildCompIn.vue'
    const textModel = ref('init')
</script>
```

## 5️⃣ [Part 5] 반응형 감시자 (Watchers) & 비동기 API 연동

### 실습 10: watch 반응형 상태 감시 및 Yes/No API 호출 (YesNoQuestion.vue)
- **접속 URL**: `/yes-no-question`
- **핵심 동작 원리**:
  - `watch(source, callback)`: 특정 반응형 상태(`question`)를 감시하고, 값이 변경될 때마다 부수 효과(Side Effect, 예: 비동기 네트워크 요청)를 수행합니다.
  - 사용자가 물음표(`?`)를 입력하면 `fetch('https://yesno.wtf/api')`를 비동기 호출하여 API 응답(`yes`/`no` 텍스트 및 관련 GIF 이미지 URL)을 화면에 실시간으로 업데이트합니다.

```vue
<!-- exam0902/src/pages/YesNoQuestion.vue -->
<script setup>
    import { ref, watch } from 'vue'

    const question = ref('')
    const answer = ref('질문에는 일반적으로 물음표가 포함됩니다.')
    const src = ref('')
    
    // watch는 ref에서 직접 작동합니다.
    watch(question, async (newQuestion, oldQuestion) => {
        if (newQuestion.indexOf('?') > -1) {
            answer.value = "생각 중..."
            try {
                const res = await fetch('https://yesno.wtf/api')
                await res.json().then(content => {
                    if (content.answer === 'yes') {
                        answer.value = '네'
                    } else {
                        answer.value = '아니오'
                    }
                    src.value = content.image
                })
            } catch (error) {
                answer.value = "에러! API에 연결할 수 없습니다. " + error
            }
        }
    })
</script>

<template>
    <v-container>
        <v-col>
            <p>
                예/아니오 질문:
                <input v-model="question"/>
            </p>

            <p>응답: {{ answer }}</p>
            <img :src="src"/>
        </v-col>
    </v-container>
</template>

<style scoped>
    input {
        border-style: solid;
        width: 400px;
    }
</style>
```

## 7️⃣ [Part 7] 컴포넌트 라이프사이클 훅 (Lifecycle Hooks)

### 실습 13: 마운트/업데이트/언마운트 생명주기 관찰 (LifeCycleHookComp.vue ↔ LifeCycleHookPage.vue)
- **접속 URL**: `/life-cycle-hook-page`
- **핵심 동작 원리**:
  - `onMounted`: 컴포넌트가 DOM에 처음 삽입 완료되었을 때 호출됩니다.
  - `onUpdated`: 반응형 상태 변경으로 인해 DOM 리렌더링이 완료되었을 때 호출됩니다.
  - `onUnmounted`: 컴포넌트가 파괴되고 DOM에서 제거되었을 때 호출됩니다.
  - 부모의 `v-if="isMounted"` 토글을 통해 자식 컴포넌트의 마운트 및 언마운트 라이프사이클을 실시간으로 확인합니다.

```vue
<!-- exam0902/src/components/LifeCycleHookComp.vue -->
<template>
    <div>
        <div>count: {{ count }}</div>
        <v-btn class="ma-2" prepend-icon="$vuetify" @click="update">업데이트</v-btn>
        <v-btn class="ma-2" prepend-icon="$vuetify" @click="unmount">언마운트</v-btn>
    </div>
</template>

<script setup>
    import { onMounted, onUnmounted, onUpdated, ref } from 'vue';
    
    onMounted(() => { console.log('컴포넌트가 마운트 됐습니다.') })
    onUpdated(() => { console.log('컴포넌트가 업데이트 됐습니다.') })
    onUnmounted(() => { console.log('컴포넌트가 언마운트 됐습니다.') })
    
    const count = ref(0)
    const update = () => { count.value++ }
    const emit = defineEmits(['unmountEvt'])
    const unmount = () => { emit('unmountEvt') }
</script>
```

```vue

</template>
```

## 💡 핵심 문법 및 개념 정리 표 (Key Takeaways)

| 문법 / 개념 | 용도 및 설명 | 예시 코드 |
|------------|-------------|-----------|
| **`defineProps()`** | 부모로부터 전달받는 속성(Props) 정의 (컴파일러 매크로) | `const props = defineProps(['title'])` |
| **`defineEmits()`** | 자식이 부모에게 발생시킬 커스텀 이벤트 선언 | `const emit = defineEmits(['enlarge-text'])` |
| **`defineModel()` (Vue 3.4+)** | 부모 `v-model`과 자식 내부 ref를 원클릭 양방향 동기화 | `const model = defineModel()`, `const title = defineModel('title')` |
| **`<slot />`** | 부모 템플릿의 자식 요소를 컴포넌트 내부에 주입 (컨텐츠 배포) | `<slot />` |
| **`watch()`** | 특정 반응형 상태의 변화를 감시하여 부수 효과(비동기 API 등) 실행 | `watch(question, async (newVal) => { ... })` |
| **Template Ref (`ref`)** | DOM 엘리먼트 또는 자식 컴포넌트 인스턴스에 직접 접근 | `<input ref="inputRef" />`, `inputRef.value.focus()` |
| **`defineExpose()`** | `<script setup>` 컴포넌트에서 부모에게 공개할 속성/메서드 지정 | `defineExpose({ count, openModal })` |
| **`onMounted()`** | 컴포넌트가 DOM에 마운트된 직후 1회 실행 | `onMounted(() => { console.log('mounted') })` |
| **`onUpdated()`** | 반응형 상태 변화로 DOM 리렌더링 완료 후 실행 | `onUpdated(() => { ... })` |
| **`onUnmounted()`** | 컴포넌트가 파괴되고 DOM에서 제거된 직후 실행 | `onUnmounted(() => { ... })` |
| **`v-navigation-drawer`** | Vuetify 사이드바 내비게이션 드로어 (`app`, `permanent`, `location`) | `<v-navigation-drawer location="right" permanent>` |
