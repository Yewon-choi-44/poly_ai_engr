**동작 원리:**
- `enctype="multipart/form-data"` 속성이 없으면 파일의 바이너리 데이터가 전송되지 않아 파일 업로드가 불가능합니다.

- `<input type="file">`: 파일 선택 다이얼로그를 여는 폼 요소입니다.

#### 📄 `fileupload01_process.jsp` — cos.jar 단일 파일 처리

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<%@ page import="com.oreilly.servlet.MultipartRequest"%>
<%@ page import="com.oreilly.servlet.multipart.DefaultFileRenamePolicy"%>
<%@ page import="java.util.Enumeration"%>
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>파일 업로드 처리 - cos.jar 단일</title>
</head>
<body>
    <%
        // 업로드 저장 경로
        String saveFolder = "C:\\upload";
        // 최대 파일 크기 (5MB)
        int maxSize = 5 * 1024 * 1024;
        // 인코딩
        String encoding = "utf-8";

        // MultipartRequest 객체 생성
        // 파일명 중복 시 자동으로 파일명을 변경 (DefaultFileRenamePolicy)
        MultipartRequest multi = new MultipartRequest(
            request,
            saveFolder,
            maxSize,
            encoding,
            new DefaultFileRenamePolicy()
        );
    %>
    <h2>업로드 결과 (일반 파라미터)</h2>
    <%
        // 일반 폼 파라미터 순회
        Enumeration paramNames = multi.getParameterNames();
        while (paramNames.hasMoreElements()) {
            String paramName = (String) paramNames.nextElement();
            String paramValue = multi.getParameter(paramName);
    %>
        <%= paramName %> : <%= paramValue %><br>
    <%
        }
    %>

    <h2>업로드 결과 (파일 파라미터)</h2>
    <%
        // 파일 파라미터 순회
        Enumeration fileNames = multi.getFileNames();
        while (fileNames.hasMoreElements()) {
            String fileName = (String) fileNames.nextElement();
            // 서버에 저장된 파일명 (중복 시 변경된 이름)
            String filesystemName  = multi.getFilesystemName(fileName);
            // 클라이언트가 업로드한 원본 파일명
            String originalFileName = multi.getOriginalFileName(fileName);
            // MIME 타입 (예: image/jpeg)
            String contentType = multi.getContentType(fileName);
            // 파일 크기 (bytes)
            long fileSize = multi.getFile(fileName) != null
                            ? multi.getFile(fileName).length() : 0;
    %>
        <b>폼 필드명:</b> <%= fileName %><br>
        <b>서버 저장 파일명:</b> <%= filesystemName %><br>
        <b>원본 파일명:</b> <%= originalFileName %><br>
        <b>MIME 타입:</b> <%= contentType %><br>
        <b>파일 크기:</b> <%= fileSize %> bytes<br>
        <hr>
    <%
        }
    %>
</body>
</html>
```

**동작 원리:**
- `MultipartRequest` 생성자 호출 시점에 파일이 `saveFolder` 경로에 저장됩니다.
- `DefaultFileRenamePolicy`: 이미 같은 이름의 파일이 서버에 존재할 경우, 자동으로 `파일명1.확장자`, `파일명2.확장자` 형식으로 이름을 변경하여 저장합니다.
- `getParameterNames()` / `getParameter()`: 일반 텍스트 파라미터 접근 (`name`, `subject` 등).
- `getFileNames()`: 파일 필드의 `name` 속성값을 Enumeration으로 반환합니다.
- `getFilesystemName()`: 실제 서버 디스크에 저장된 파일명 (중복 처리 후 이름).
- `getOriginalFileName()`: 클라이언트가 업로드한 원본 파일명.

```jsp
            String origName = multi.getOriginalFileName(name);

        </tr>
    <%
        }
```

#### 📄 `fileupload03_process.jsp` — Commons 단일 파일 처리

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<%@ page import="java.util.List"%>
<%@ page import="java.util.Iterator"%>
<%@ page import="java.io.File"%>
<%@ page import="org.apache.commons.fileupload.DiskFileUpload"%>
<%@ page import="org.apache.commons.fileupload.FileItem"%>
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>파일 업로드 처리 - Commons 단일</title>
</head>
<body>
    <%
        String saveFolder = "C:\\upload";

        // DiskFileUpload 객체 생성
        DiskFileUpload upload = new DiskFileUpload();

        // 요청 파싱 → FileItem 리스트 반환
        List<FileItem> items = upload.parseRequest(request);
        Iterator<FileItem> iter = items.iterator();

        while (iter.hasNext()) {
            FileItem fileItem = iter.next();

            // isFormField() == false → 파일 아이템
            if (!fileItem.isFormField()) {
                String fileName = fileItem.getName();

                // Windows 경로 구분자 처리: 전체 경로에서 파일명만 추출
                if (fileName != null && !fileName.isEmpty()) {
                    int lastIndex = fileName.lastIndexOf("\\");
                    if (lastIndex >= 0) {
                        fileName = fileName.substring(lastIndex + 1);
                    }
                    // 파일 저장
                    File saveFile = new File(saveFolder, fileName);
                    fileItem.write(saveFile);
    %>
        <b>저장된 파일명:</b> <%= fileName %><br>
        <b>저장 경로:</b> <%= saveFile.getAbsolutePath() %><br>
    <%
                }
            }
        }
    %>
</body>
</html>
```

**동작 원리:**
- `DiskFileUpload.parseRequest(request)`: `multipart/form-data` 요청을 파싱하여 각 파트를 `FileItem` 객체 리스트로 반환합니다.
- `FileItem.isFormField()`: `false`이면 파일 필드, `true`이면 일반 텍스트 필드입니다.
- `FileItem.getName()`: 클라이언트 OS에 따라 전체 경로가 포함될 수 있으므로 `lastIndexOf("\\")` 처리로 순수 파일명만 추출합니다.
- `FileItem.write(File)`: 해당 `FileItem`의 데이터를 지정한 `File` 객체 경로에 저장합니다.

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<%@ page import="java.util.List"%>
<%@ page import="java.util.Iterator"%>
<%@ page import="java.io.File"%>
<%@ page import="org.apache.commons.fileupload.DiskFileUpload"%>
<%@ page import="org.apache.commons.fileupload.FileItem"%>
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>파일 업로드 처리 - Commons 파일+텍스트</title>
</head>
<body>
    <%
        String saveFolder = "C:\\upload";

        DiskFileUpload upload = new DiskFileUpload();

        // 최대 허용 파일 크기 설정 (1MB)
        upload.setSizeMax(1000000);
        // 메모리 임계값 설정 (4KB 초과 시 임시 파일 사용)
        upload.setSizeThreshold(4096);
        // 임시 파일 저장 경로 설정
        upload.setRepositoryPath(saveFolder);

        List<FileItem> items = upload.parseRequest(request);
        Iterator<FileItem> iter = items.iterator();
    %>
    <h2>업로드 결과</h2>
    <table border="1">
        <tr>
            <th>구분</th><th>필드명</th><th>값 / 파일 정보</th>
        </tr>
    <%
        while (iter.hasNext()) {
            FileItem item = iter.next();

            if (item.isFormField()) {
                // 일반 텍스트 폼 필드 처리
                String fieldName  = item.getFieldName();
                String fieldValue = item.getString("utf-8"); // 인코딩 지정
    %>
        <tr>
            <td>텍스트</td>
            <td><%= fieldName %></td>
            <td><%= fieldValue %></td>
        </tr>
    <%
            } else {
                // 파일 필드 처리
                String fieldName   = item.getFieldName();
                String fileName    = item.getName();
                String contentType = item.getContentType();
                long   fileSize    = item.getSize();

                if (fileName != null && !fileName.isEmpty()) {
                    int lastIndex = fileName.lastIndexOf("\\");
                    if (lastIndex >= 0) {
                        fileName = fileName.substring(lastIndex + 1);
                    }
                    File saveFile = new File(saveFolder, fileName);
                    item.write(saveFile);
                }
    %>
        <tr>
            <td>파일</td>
            <td><%= fieldName %></td>
            <td>
                파일명: <%= fileName %><br>
                MIME: <%= contentType %><br>
                크기: <%= fileSize %> bytes
            </td>
        </tr>
    <%
            }
        }
    %>
    </table>
</body>
</html>
```

**동작 원리:**
- `setSizeMax(bytes)`: 요청 전체(또는 단일 파일)의 최대 허용 크기를 제한합니다. 초과 시 예외 발생.
- `setSizeThreshold(bytes)`: 이 크기 이하의 파일은 메모리에, 초과하면 임시 파일(`RepositoryPath`)에 저장됩니다.
- `setRepositoryPath(path)`: 임계값을 초과한 데이터의 임시 저장 경로.
- `item.isFormField() == true`: 일반 텍스트 필드 → `getFieldName()`(필드명), `getString("utf-8")`(값).
- `item.isFormField() == false`: 파일 필드 → `getName()`(파일명), `getContentType()`(MIME), `getSize()`(바이트 크기), `write(File)`(저장).

## 3. 핵심 JSP/Java 태그 및 문법

### 3-1. 파일 업로드 필수 조건

| 조건 | 설명 |
|---|---|
| `method="post"` | 파일 데이터는 HTTP 본문(body)으로 전송되어야 하므로 POST 필수 |
| `enctype="multipart/form-data"` | 파일 바이너리 데이터를 멀티파트 형식으로 인코딩 (기본값 `application/x-www-form-urlencoded`는 파일 전송 불가) |
| `<input type="file">` | 파일 선택 UI 요소, `name` 속성으로 서버에서 식별 |

### 3-2. cos.jar — `MultipartRequest` 주요 API

```java
// 생성자 (요청, 저장경로, 최대크기, 인코딩, 파일명중복정책)
MultipartRequest multi = new MultipartRequest(
    request, saveFolder, maxSize, encoding, new DefaultFileRenamePolicy()
);

// 일반 파라미터
Enumeration paramNames = multi.getParameterNames();  // 파라미터 이름 목록
String value = multi.getParameter("name");           // 파라미터 값

// 파일 파라미터
Enumeration fileNames = multi.getFileNames();             // 파일 필드명 목록
String fsName   = multi.getFilesystemName("filename");    // 서버 저장 파일명
String origName = multi.getOriginalFileName("filename");  // 원본 파일명
String cType    = multi.getContentType("filename");       // MIME 타입
File   file     = multi.getFile("filename");              // File 객체
long   size     = file.length();                          // 파일 크기
```

### 3-3. Apache Commons FileUpload — `DiskFileUpload` / `FileItem` 주요 API

```java
DiskFileUpload upload = new DiskFileUpload();
upload.setSizeMax(1000000);          // 최대 파일 크기 (bytes)
upload.setSizeThreshold(4096);       // 메모리 임계값 (bytes)
upload.setRepositoryPath(path);      // 임시 파일 저장 경로

List<FileItem> items = upload.parseRequest(request); // 요청 파싱

for (FileItem item : items) {
    if (item.isFormField()) {
        // 일반 텍스트 필드
        String fieldName = item.getFieldName();    // 필드명 (name 속성)
        String value     = item.getString("utf-8"); // 필드값
    } else {
        // 파일 필드
        String fieldName   = item.getFieldName();   // 필드명
        String fileName    = item.getName();         // 파일명 (경로 포함 가능)
        String contentType = item.getContentType(); // MIME 타입
        long   size        = item.getSize();         // 파일 크기 (bytes)
        item.write(new File(saveFolder, fileName));  // 파일 저장
    }
}
```

### 3-4. 두 방식 비교

| 항목 | cos.jar (MultipartRequest) | Commons FileUpload (DiskFileUpload) |
|---|---|---|
| 사용 라이브러리 | `cos.jar` | `commons-fileupload.jar` + `commons-io.jar` |
| API 복잡도 | 간단 | 상대적으로 복잡 |
| 파일명 중복 처리 | `DefaultFileRenamePolicy` 자동 처리 | 수동 처리 필요 |
| 크기 제한 설정 | 생성자 파라미터로 지정 | `setSizeMax()` 메서드 |
| 메모리/임시파일 제어 | 제한적 | `setSizeThreshold()`, `setRepositoryPath()` |
| 일반 필드 접근 | `getParameter()` | `item.getString("utf-8")` |
| 파일 저장 | 생성자 호출 시 자동 저장 | `item.write(File)` 명시 호출 |
| 현재 유지보수 | 비권장 (오래된 라이브러리) | Apache에서 유지보수 중 |

## 4. BookMarket 프로젝트 반영 사항 (7장: 도서 이미지 등록)

7장에서는 BookMarket 도서 쇼핑몰에 **도서 이미지 파일 업로드 기능**이 추가됩니다.

### 변경된 파일

#### `addBook.jsp` — 도서 등록 폼에 이미지 업로드 필드 추가

기존 텍스트 필드(도서명, 저자, 가격 등) 외에 이미지 파일 업로드 필드가 추가되며, 폼의 `enctype`이 변경됩니다.

```jsp
<%-- 기존 폼에서 enctype 속성 추가 --%>
<form action="addBook_process.jsp" method="post"
      enctype="multipart/form-data">

    <%-- 기존 텍스트 필드들 ... --%>
    <label>도서명</label>
    <input type="text" name="bookName"><br>
    <label>저자</label>
    <input type="text" name="author"><br>
    <label>가격</label>
    <input type="text" name="price"><br>

    <%-- 이미지 파일 업로드 필드 (7장에서 추가) --%>
    <label>도서 이미지</label>
    <input type="file" name="bookImage" accept="image/*"><br>

    <input type="submit" value="도서 등록">
</form>
```

#### `addBook_process.jsp` — 파일 업로드 처리 및 도서 등록 로직

```jsp
<%@ page import="com.oreilly.servlet.MultipartRequest"%>
<%@ page import="com.oreilly.servlet.multipart.DefaultFileRenamePolicy"%>
<%
    // 이미지 저장 경로 (BookMarket 이미지 폴더)

    MultipartRequest multi = new MultipartRequest(
        request,
        imageSaveDir,
        5 * 1024 * 1024,   // 5MB
        "utf-8",
        new DefaultFileRenamePolicy()

    // 텍스트 파라미터 추출
    String bookName = multi.getParameter("bookName");
    String author   = multi.getParameter("author");

    String imageFileName = multi.getFilesystemName("bookImage");

    // 이후 Book 객체 생성 및 BookRepository에 저장 (기존 로직)
    // ...
%>
```

### 반영 내용 요약

| 항목 | 변경 전 (6장) | 변경 후 (7장) |
|---|---|---|
| `addBook.jsp` 폼 enctype | `application/x-www-form-urlencoded` (기본값) | `multipart/form-data` |
| 도서 이미지 입력 | 없음 (텍스트로 파일명 직접 입력) | `<input type="file">` 파일 업로드 |

| 이미지 저장 | 없음 | 서버 `resources/images/` 폴더에 저장 |
| Book 객체 imageFileName | 하드코딩 또는 텍스트 입력 | 업로드된 실제 파일명으로 설정 |

## 5. 💡 핵심 문법 정리 표 (Key Takeaways)

### 파일 업로드 기초

| 개념 | 내용 |
|---|---|
| `enctype="multipart/form-data"` | 파일 업로드를 위한 필수 폼 인코딩 타입 |
| `method="post"` | 파일 업로드 시 반드시 POST 사용 |
| `<input type="file" name="...">` | 파일 선택 UI, `name`으로 서버에서 식별 |
| `accept="image/*"` | 선택 가능한 파일 타입 힌트 (브라우저 필터링) |
| `C:\\upload` | 파일 저장 경로 (Windows 절대 경로, 실제 디렉토리 사전 생성 필요) |

### cos.jar (MultipartRequest)

| API | 설명 |
|---|---|
| `new MultipartRequest(req, dir, size, enc, policy)` | 생성자 호출 시 요청 파싱 및 파일 자동 저장 |
| `new DefaultFileRenamePolicy()` | 파일명 중복 시 자동 번호 부여 정책 |
| `getParameterNames()` | 일반 파라미터 이름 목록 (Enumeration) |
| `getParameter(name)` | 일반 파라미터 값 조회 |
| `getFileNames()` | 파일 파라미터 이름 목록 (Enumeration) |
| `getFilesystemName(name)` | 서버에 실제 저장된 파일명 |
| `getOriginalFileName(name)` | 클라이언트가 보낸 원본 파일명 |
| `getContentType(name)` | 파일의 MIME 타입 |
| `getFile(name)` | 저장된 파일의 `File` 객체 |

### Apache Commons FileUpload (DiskFileUpload)

| API | 설명 |
|---|---|
| `new DiskFileUpload()` | 업로더 객체 생성 |
| `setSizeMax(bytes)` | 최대 허용 파일 크기 설정 |
| `setSizeThreshold(bytes)` | 메모리 저장 임계값 (초과 시 임시 파일 사용) |
| `setRepositoryPath(path)` | 임시 파일 저장 경로 |
| `parseRequest(request)` | 요청 파싱 → `List<FileItem>` 반환 |
| `FileItem.isFormField()` | `true`: 일반 텍스트 필드, `false`: 파일 필드 |
| `FileItem.getFieldName()` | 폼 필드의 `name` 속성값 |
| `FileItem.getString("utf-8")` | 텍스트 필드 값 (인코딩 지정) |
| `FileItem.getName()` | 업로드된 파일명 (경로 포함 가능 → 파싱 필요) |
| `FileItem.getContentType()` | 파일 MIME 타입 |
| `FileItem.getSize()` | 파일 크기 (bytes) |
| `FileItem.write(File)` | 파일을 지정 경로에 저장 |

### 파일명 경로 파싱 패턴 (Windows 클라이언트 대응)

```java
// 일부 브라우저는 전체 경로(C:\Users\...\파일명.jpg)를 전송하므로 파일명만 추출
String fileName = item.getName(); // 예: "C:\\Users\\user\\Desktop\\photo.jpg"
int lastIndex = fileName.lastIndexOf("\\");
if (lastIndex >= 0) {
    fileName = fileName.substring(lastIndex + 1); // → "photo.jpg"
}
```

> **참고:** cos.jar는 비교적 오래된 라이브러리이며, 현대 프로젝트에서는 Apache Commons FileUpload나 Servlet 3.0 이상의 `request.getPart()` / `@MultipartConfig` 방식을 권장합니다. 본 실습은 교재 학습 목적으로 두 방식 모두 다루었습니다.
