## 2. 실습 파일 코드 및 동작 원리

### 📄 first.jsp — jsp:forward

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
	<meta charset="UTF-8">
	<title>Action Tag</title>
</head>
<body>
	<h3>이 파일은 first.jsp입니다.</h3>
	<jsp:forward page="second.jsp" />
	<p> ===first.jsp의 페이지=====
</body>
</html>
```

**동작 원리**  
- `<jsp:forward page="second.jsp" />` 실행 시 버퍼가 초기화되고 `second.jsp`로 제어가 완전히 넘어갑니다.
- `forward` 이후의 `<p>` 태그는 **절대 출력되지 않습니다** (버퍼 초기화).
- 클라이언트 URL은 여전히 `first.jsp`로 표시됩니다 (서버 내부 이동).

---

### 📄 second.jsp — 표현문 태그

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
...

```

**동작 원리**  
- `<%= new java.util.Date() %>` : `out.print(new java.util.Date())`와 동일합니다.
- `first.jsp`에서 forward 되어 실행됩니다.

### 📄 firstInclude.jsp + secondInclude.jsp — jsp:include

```jsp
<!-- firstInclude.jsp -->
<body>
	<h3>이 파일은 firstInclude.jsp입니다.</h3>
	<jsp:include page="secondInclude.jsp" flush="false" />
	<p>Jakarta Server Page</p>
</body>
```

```jsp
<!-- secondInclude.jsp -->
<body>
	<h3>이 파일은 secondIncludeActionTag.jsp입니다.</h3>
	Today is : <%=new java.util.Date() %>
</body>
```

**동작 원리**  
- `forward`와 달리 `include`는 버퍼를 초기화하지 않습니다.
- `secondInclude.jsp`의 출력 결과가 `firstInclude.jsp` 내에 삽입된 후, `<p>Jakarta Server Page</p>`가 이어서 출력됩니다.
- `flush="false"` : include 전에 버퍼를 플러시하지 않습니다.

### 📄 param01.jsp + param01_data.jsp — jsp:param

```jsp
<!-- param01.jsp -->
<body>
	<h3>param 액션 태그</h3>
	<jsp:forward page="param01_data.jsp">
		<jsp:param name="id" value="admin" />
		<jsp:param name="name" value='<%=java.net.URLEncoder.encode("관리자") %>' />
	</jsp:forward>
</body>
```

```jsp
<!-- param01_data.jsp -->
<body>
	<p> 아이디 : <%=request.getParameter("id") %>
		<% 
			String name=request.getParameter("name"); 
		%>
	<p> 이 름 : <%=java.net.URLDecoder.decode(name) %>
</body>
```

**동작 원리**  
- `<jsp:param>`으로 파라미터를 전달할 때, 한글은 `URLEncoder.encode()`로 인코딩한 후 전달하고, 수신 측에서 `URLDecoder.decode()`로 복원합니다.
- 전달된 파라미터는 `request.getParameter("name")`으로 조회합니다.

### 📄 useBean01.jsp ~ getProperty02.jsp — JavaBeans 액션 태그

```jsp
<!-- useBean01.jsp: java.util.Date를 빈으로 사용 -->
<jsp:useBean id="date" class="java.util.Date" />
<p> <%  out.print("오늘의 날짜 및 시각"); %>
<p> <%=date %>
```

```jsp
<!-- useBean02.jsp: Calculator 빈 사용 -->
<jsp:useBean id="bean" class="dao.Calculator" />
<%
	int m=bean.process(5);
	out.print("5의 3제곱 : " + m);
%>
```

```jsp
<!-- useBean04.jsp: Person 빈 값 설정 후 useBean03.jsp include -->
<jsp:useBean id="person" class="dao.Person" scope="request" />
<p> 아이디 : <%=person.getId() %>
<p> 이 름 : <%=person.getName() %>
<%
	person.setId(20230824);
	person.setName("홍길동");
%>
<jsp:include page="useBean03.jsp" />
```

```jsp
<!-- getProperty02.jsp: setProperty + getProperty 조합 -->
<jsp:useBean id="person" class="dao.Person"></jsp:useBean>
<jsp:setProperty name="person" property="id" value="20230824" />
<jsp:setProperty name="person" property="name" value="홍길동" />
<p> 아이디 : <jsp:getProperty property="id" name="person" />
<p> 이 름 : <jsp:getProperty property="name" name="person" />
```

**동작 원리**
- `scope` 속성: `page`(기본, 현재 페이지) / `request`(요청 범위, include된 페이지 간 공유) / `session` / `application`
- `useBean04.jsp`에서 `person` 빈을 `request` scope로 생성하고 값을 설정한 뒤, `jsp:include`로 `useBean03.jsp`를 포함하면 **같은 request scope의 빈을 공유**합니다.

### 📄 dao/Person.java

```java
package dao;

public class Person {
	private int id = 20230821;
	private String name = "홍길순";
	
	public Person() { }
	
	public int getId() { return id; }
	public void setId(int id) { this.id = id; }
	public String getName() { return name; }
	public void setName(String name) { this.name = name; }
}
```

**JavaBean 작성 규칙**
- `java.io.Serializable` 구현 (권장)
- 기본 생성자(인수 없는 생성자) 필수
- 프로퍼티는 `private`, Getter/Setter는 `public`
- Getter: `get프로퍼티명()`, Setter: `set프로퍼티명(값)`

## 5. 💡 핵심 문법 정리 표 (Key Takeaways)

### 액션 태그 비교

| 태그 | 문법 | 특징 |
|------|------|------|
| `jsp:forward` | `<jsp:forward page="URL" />` | 버퍼 초기화 후 제어 이동, 이후 코드 미실행 |
| `jsp:include` | `<jsp:include page="URL" flush="false" />` | 대상 페이지 실행 결과를 현재 위치에 삽입 |
| `jsp:param` | `<jsp:param name="k" value="v" />` | `forward`/`include` 내에서 파라미터 추가 전달 |
| `jsp:useBean` | `<jsp:useBean id="b" class="pkg.Cls" scope="..." />` | 빈 생성 또는 기존 빈 참조 |
| `jsp:setProperty` | `<jsp:setProperty name="b" property="p" value="v" />` | 빈 프로퍼티 값 설정 |
| `jsp:getProperty` | `<jsp:getProperty name="b" property="p" />` | 빈 프로퍼티 값 출력 |

### include 디렉티브 vs include 액션 태그

| 구분 | include 디렉티브 `<%@ include %>` | include 액션 태그 `<jsp:include>` |
|------|----------------------------------|-----------------------------------|
| 처리 시점 | **변환 시** (물리적 병합) | **런타임 시** (실행 결과 삽입) |
| 서블릿 | 하나의 서블릿으로 합쳐짐 | 각자 별도의 서블릿으로 컴파일 |
| 변수 공유 | 가능 (같은 스코프) | 불가능 (별도 스코프) |
| 용도 | 정적 UI 부품 (머리글/바닥글) | 동적으로 변하는 콘텐츠 삽입 |

### useBean scope 비교

| scope | 유효 범위 | 공유 대상 |
|-------|----------|----------|
| `page` | 현재 JSP 페이지 | 해당 페이지만 |
| `request` | 하나의 HTTP 요청 | forward/include된 페이지 간 |
| `session` | 브라우저 세션 | 같은 사용자 요청 전체 |
| `application` | 웹 애플리케이션 전체 | 모든 사용자 공유 |
