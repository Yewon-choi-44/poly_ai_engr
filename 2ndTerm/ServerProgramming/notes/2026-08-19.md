## 2. 실습 파일 코드 및 동작 원리

### 📄 Hello0819.jsp

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>Hello!</title>
</head>
<body>
	<h1>Hello JSP!!</h1>
	Hello! Java Server pages.
</body>
</html>
```

**동작 원리**
- `<%@ page ... %>` 디렉티브로 문자 인코딩을 UTF-8로 설정합니다.
- JSP 태그 없이 순수 HTML로 구성된 가장 기초적인 JSP 파일입니다.
- Tomcat이 이 파일을 서블릿으로 변환·컴파일하여 클라이언트에 응답합니다.
- URL: `http://localhost:8080/JSP0819/Hello0819.jsp`

### 📄 BookMarket/Welcome0819.jsp

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
pageEncoding="UTF-8"%>
<%@ page import ="java.util.Date" %>

<!DOCTYPE html>
<html>
<head>
	<meta charset="UTF-8">
	<title>Welcome</title>
	<link href = "https://cdn.jsdelivr.net/npm/bootstrap@5.3.1/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
	<div class = "container py-4">
		<header class = "pb-3 mb-4 border-bottom">
			<a href = "./Welcome.jsp" class = "d-flex align-items-center text-dark text-decoration-none">
				<svg width="32" height="32" fill="currentColor" class="bi bi-house-fill" viewBox="0 0 16 16">
					<path d = "M8.707 1.5a1 1 0 0 0-1.414 0L.646 8.146a.5.5 0 0 0 .708.708L82.207l6 .646 6.647a.5.5 0 0 0 .708-.708L13 5.793V2.5a.5.5 0 0 0-.5-.5h-1a.5.5 0 0 0-.5.5v1.293L8.707 1.5Z"/>
				</svg>
					<span class = "fs-4">Home</span>
			</a>
		</header>

	<%! 
	String greeting = "Welcome to Book Shopping Mall";
	String tagline = "Welcome to Web Market!"; 
	%>
	
	<div class = "p-5 mb-4 bg-body-tertiary rounded-3">
		<div class="container-fluid py-5">
			<h1 class="display-5 fw-bold">
			<%= greeting %></h1>
			<p class="col-md-8 fs-4">BookMarket</p>
			</div>
	</div>
	<div class = "row align-items-md-stretch text-center">
		<div class = "col-md-12">
			<div class = "h-100 p-5">
				<h3><%= tagline %></h3>
				<%
					Date day = new java.util.Date();
					String am_pm;
					int hour = day.getHours();
					int minute=day.getMinutes();
					int second=day.getSeconds();
					
					if (hour / 12 == 0){
						am_pm = "AM";
					} else {
						am_pm = "PM";
						hour = hour - 12;
					}
					String CT = hour + ":" + minute + ":" + second + " " + am_pm;
					out.println("현재 접속 시각: " + CT + "\n");
					%>
			</div>
		</div>
	</div>
	<footer class = "pt-3 mt-4 text-body-secondary border-top">
		&copy; BookMarket
	</footer>


	</div>
</body>
</html>
```

**동작 원리**
- `<%@ page import="java.util.Date" %>` : `java.util.Date` 클래스를 임포트합니다.
- `<%! ... %>` **선언문 태그**: `greeting`, `tagline` 문자열을 **전역 변수**로 선언합니다. 서블릿 클래스의 멤버 변수가 됩니다.
- `<%= greeting %>` **표현문 태그**: 변수 값을 HTML에 출력합니다. `out.print(greeting)`과 동일합니다.
- `<% ... %>` **스크립틀릿 태그**: Java 로직(시각 계산, if 분기)을 실행합니다. `out.println()`으로 접속 시각을 출력합니다.
- Bootstrap 5.3.1 CDN을 적용한 반응형 레이아웃입니다.
- URL: `http://localhost:8080/BookMarket/Welcome0819.jsp`

## 3. 실행 환경 및 구조

```
[브라우저] → http://localhost:8080/JSP0819/Hello0819.jsp
              http://localhost:8080/JSP0819/Welcome.jsp
              http://localhost:8080/BookMarket/Welcome0819.jsp
```

- 부트스트랩 `<link>` 태그를 `<head>` 내에 삽입하여 CSS 프레임워크 연동

## 5. 💡 핵심 문법 정리 표 (Key Takeaways)

### JSP 동작 원리

| 단계 | 설명 |
|------|------|
| 1. 변환 | `.jsp` → `.java` (서블릿 소스) |
| 2. 컴파일 | `.java` → `.class` (바이트코드) |
| 3. 실행 | 웹 컨테이너(Tomcat)가 서블릿 실행 |
| 4. 응답 | 동적으로 생성된 HTML을 클라이언트로 전송 |

### 스크립트 태그 비교

| 태그 | 문법 | 서블릿 변환 위치 | 용도 |
|------|------|----------------|------|
| 선언문 | `<%! ... %>` | 클래스 멤버 (전역) | 전역 변수·메서드 선언 |
| 스크립틀릿 | `<% ... %>` | `_jspService()` 내부 | Java 로직, 제어문 |
| 표현문 | `<%= ... %>` | `out.print(...)` | 값 출력 (세미콜론 없음) |
| JSP 주석 | `<%-- ... --%>` | 서블릿 변환 시 제거 | 주석 (클라이언트 미노출) |

### page 디렉티브 주요 속성

| 속성 | 예시 | 설명 |
|------|------|------|
| `language` | `language="java"` | 스크립팅 언어 지정 |
| `contentType` | `contentType="text/html; charset=UTF-8"` | 응답 MIME 타입 및 인코딩 |
| `pageEncoding` | `pageEncoding="UTF-8"` | JSP 파일 자체 인코딩 |
| `import` | `import="java.util.Date"` | Java 클래스 임포트 |
