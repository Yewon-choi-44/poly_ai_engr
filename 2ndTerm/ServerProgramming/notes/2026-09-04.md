### 🗂️ form 태그 실습

#### `form01.jsp` — 기본 text input

```jsp
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<html>
<head><title>form01</title></head>
<body>
  <form action="form01_process.jsp" method="post">
    이름: <input type="text" name="username" /><br/>
    <input type="submit" value="전송" />
  </form>
</body>
</html>
```

> 가장 기본적인 `<form>` 태그 구조. `action`에 처리 페이지, `method`에 전송 방식을 지정한다.

---

#### `form02.jsp` — text + password + 한글 처리

```jsp
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<html>
<body>
  <form action="form02_process.jsp" method="post">
    아이디: <input type="text"     name="id"     /><br/>
    비밀번호: <input type="password" name="passwd" /><br/>
    <input type="submit" value="로그인" />
  </form>
</body>
</html>
```

```jsp
<%-- form02_process.jsp --%>
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<%
  request.setCharacterEncoding("utf-8");
  String id     = request.getParameter("id");
  String passwd = request.getParameter("passwd");
%>
아이디: <%= id %> <br/>
비밀번호: <%= passwd %>
```

> `password` 타입은 입력값이 마스킹될 뿐, 서버에서 처리하는 방법은 `text`와 동일하다.  
> POST 방식에서 한글이 깨지지 않도록 **처리 페이지 최상단**에서 `request.setCharacterEncoding("utf-8")`을 반드시 호출해야 한다.

#### `form03.jsp` — select + radio + checkbox 조합

```jsp

    <%-- radio --%>
```

#### `form05.jsp` / `form05_process.jsp` — 동일 name 체크박스 (`getParameterValues`)

```jsp
<%-- form05.jsp — form04와 동일 폼이지만 hobby name을 통일 --%>
취미:
<input type="checkbox" name="hobby" value="독서" /> 독서
<input type="checkbox" name="hobby" value="운동" /> 운동
<input type="checkbox" name="hobby" value="영화" /> 영화
```

```jsp
<%-- form05_process.jsp --%>
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<%@ page import="java.util.Arrays" %>
<%
  request.setCharacterEncoding("utf-8");
  String[] hobbies = request.getParameterValues("hobby");
%>
취미: <%= hobbies != null ? Arrays.toString(hobbies) : "없음" %>
```

> 동일 `name` 속성을 가진 여러 체크박스는 `getParameterValues(name)`으로 **String 배열**로 받는다.  
> 아무것도 선택하지 않으면 `null`이 반환되므로 null 체크가 필수다.

#### `form06.jsp` / `form06_process.jsp` — `getParameterNames()`로 전체 파라미터 출력

```jsp
<%-- form06_process.jsp --%>
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<%@ page import="java.util.Enumeration" %>
<%
  request.setCharacterEncoding("utf-8");
  Enumeration<String> paramNames = request.getParameterNames();
%>
<table border="1">
  <tr><th>파라미터명</th><th>값</th></tr>
  <% while (paramNames.hasMoreElements()) {
       String paramName = paramNames.nextElement();
       String paramValue = request.getParameter(paramName); %>
  <tr>
    <td><%= paramName %></td>
    <td><%= paramValue %></td>
  </tr>
  <% } %>
</table>
```

> `getParameterNames()`는 요청에 포함된 **모든 파라미터 이름**을 `Enumeration<String>`으로 반환한다.  
> `while (e.hasMoreElements())` + `e.nextElement()` 패턴으로 순회하여 동적으로 테이블을 생성할 수 있다.

### 🗂️ response 내장 객체 실습

#### `response.jsp` — sendRedirect로 외부 URL 이동

```jsp
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<%
  response.sendRedirect("http://www.google.com");
%>
```

> `sendRedirect(url)`는 클라이언트(브라우저)에게 새 URL로 이동하도록 **302 응답**을 보낸다.  
> `forward`와 달리 URL이 바뀌며, 외부 사이트 이동도 가능하다.

---

#### `response01.jsp` / `response01_process.jsp` — 로그인 검증 후 리다이렉트

```jsp
<%-- response01.jsp --%>
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<form action="response01_process.jsp" method="post">
  아이디:   <input type="text"     name="id"     /><br/>
  비밀번호: <input type="password" name="passwd" /><br/>
  <input type="submit" value="로그인" />
</form>
```

```jsp
<%-- response01_process.jsp --%>
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<%
  request.setCharacterEncoding("utf-8");
  String id     = request.getParameter("id");
  String passwd = request.getParameter("passwd");

  if ("관리자".equals(id) && "1234".equals(passwd)) {
    response.sendRedirect("response01_success.jsp");
  } else {
    response.sendRedirect("response01_failed.jsp");
  }
%>
```

```jsp
<%-- response01_success.jsp --%>
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<h2>로그인 성공! 환영합니다, 관리자님.</h2>
```

```jsp
<%-- response01_failed.jsp --%>
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<h2>로그인 실패. 아이디 또는 비밀번호를 확인하세요.</h2>
```

> 조건 비교 시 `"관리자".equals(id)` 형태로 리터럴을 앞에 두면 `id`가 `null`이어도 NullPointerException이 발생하지 않는다.

#### `response02.jsp` — 5초마다 자동 새로고침

```jsp
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<%@ page import="java.util.Calendar" %>
<%
  response.setIntHeader("Refresh", 5);
  Calendar cal = Calendar.getInstance();
%>
<html>
<body>
  현재 시각: <%= cal.getTime() %>
  <br/>(5초마다 자동으로 갱신됩니다)
</body>
</html>
```

> `response.setIntHeader("Refresh", n)`은 HTTP 응답 헤더에 `Refresh: n`을 추가하여  
> 브라우저가 **n초 후 자동으로 현재 페이지를 재요청**하도록 한다.

---

#### `response03.jsp` — HTTP 에러 응답 강제 출력

```jsp
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<%
  response.sendError(404, "요청하신 페이지를 찾을 수 없습니다.");
%>
```

> `response.sendError(statusCode, message)`로 서버에서 강제로 HTTP 에러 응답을 전송한다.  
> 브라우저는 해당 에러 코드에 맞는 기본 오류 페이지 또는 `web.xml`에 설정된 에러 페이지를 표시한다.

## 3. 핵심 JSP/Java 태그 및 문법 (내장 객체 중심)

### 🔹 `request` 내장 객체 주요 메서드

| 메서드 | 반환 타입 | 설명 |
|--------|-----------|------|
| `getParameter(name)` | `String` | 단일 파라미터 값 반환. 없으면 `null` |
| `getParameterValues(name)` | `String[]` | 동일 name의 복수 파라미터를 배열로 반환 |
| `getParameterNames()` | `Enumeration<String>` | 전체 파라미터 이름 목록 |
| `setCharacterEncoding("utf-8")` | `void` | POST 요청 한글 인코딩 설정 (최상단 호출 필수) |
| `getMethod()` | `String` | 요청 방식 (`"GET"` / `"POST"`) |
| `getRequestURI()` | `String` | 요청 URI (`/JSP0904/process.jsp`) |
| `getContextPath()` | `String` | 컨텍스트 경로 (`/JSP0904`) |
| `getServerName()` | `String` | 서버 호스트명 (`localhost`) |
| `getServerPort()` | `int` | 서버 포트 (`8080`) |
| `getRemoteAddr()` | `String` | 클라이언트 IP 주소 |
| `getContentLength()` | `int` | 요청 바디 데이터 길이 (바이트) |
| `getContentType()` | `String` | 요청 콘텐츠 타입 |
| `getCharacterEncoding()` | `String` | 요청 문자 인코딩 |
| `getProtocol()` | `String` | 프로토콜 버전 (`HTTP/1.1`) |
| `getQueryString()` | `String` | GET 방식 쿼리 스트링 |
| `getHeaderNames()` | `Enumeration<String>` | 요청 헤더 이름 목록 |
| `getHeader(name)` | `String` | 특정 헤더 값 반환 |

### 🔹 `response` 내장 객체 주요 메서드

| 메서드 | 설명 |
|--------|------|
| `sendRedirect(url)` | 클라이언트를 지정 URL로 리다이렉트 (302 응답) |

### 🔹 `forward` vs `sendRedirect` 비교

| 구분 | `jsp:forward` / `RequestDispatcher.forward()` | `response.sendRedirect()` |
|------|----------------------------------------------|---------------------------|
| 처리 위치 | 서버 내부에서 처리 (클라이언트 모름) | 클라이언트에게 새 URL 요청 지시 |
| URL 변화 | 브라우저 URL **변하지 않음** | 브라우저 URL **변경됨** |
| request 공유 | request 객체 공유 가능 | 새로운 request 생성 |
| 외부 URL | 불가 | 가능 |
| HTTP 응답 코드 | 200 OK | 302 Found |

## 4. BookMarket 프로젝트 반영 사항 (5장)

### 📌 5장 핵심: 도서 상세 정보 — 내장 객체 활용

5장에서는 `request` 내장 객체를 활용하여 도서 상세 정보 페이지를 구현하는 방법을 학습했다.

#### 개념 흐름

```
books.jsp (도서 목록)
  └─ 도서 이미지/제목 클릭 (링크에 ?isbn=xxx 쿼리 파라미터 포함)
        ↓  GET 요청
book.jsp (도서 상세 정보)
  └─ request.getParameter("isbn") 으로 도서 ID 수신
  └─ 해당 도서의 상세 정보 표시
```

#### BookMarket 5장 주요 변경 파일

| 파일 | 설명 |
|------|------|
| `book.jsp` | 도서 상세 정보 페이지. `request.getParameter("isbn")`으로 도서 ID를 받아 해당 도서 정보 표시 |
| `books.jsp` | 도서 목록에서 각 도서 링크에 `?isbn={도서ID}` 쿼리 파라미터 추가 |

#### `book.jsp` 핵심 코드 패턴 (개념 예시)

```jsp
<%@ page contentType="text/html;charset=UTF-8" language="java" %>
<%@ page import="dto.Book, dao.BookRepository" %>
<jsp:useBean id="bookRepo" class="dao.BookRepository" scope="application" />
<%
  String isbn = request.getParameter("isbn");
  Book book = bookRepo.getBookById(isbn);
%>
<html>
<body>
  <h2><%= book.getName() %></h2>
  <p>저자: <%= book.getAuthor() %></p>
  <p>가격: <%= book.getPrice() %>원</p>
  <img src="<%= book.getFileName() %>" />
</body>
</html>
```

> JSP0904 실습은 내장 객체 **기초 문법** 훈련에 집중하므로 BookMarket 코드에 직접 반영하지는 않았다.  
> 그러나 5장에서 학습한 `request.getParameter()` 패턴이 BookMarket `book.jsp`의 핵심 동작 원리이다.

## 5. 💡 핵심 문법 정리 표 (Key Takeaways)

### 내장 객체 한눈에 보기

| 내장 객체 | 타입 | 주요 용도 |
|-----------|------|-----------|
| `request` | `HttpServletRequest` | 클라이언트 요청 데이터 수신 (파라미터, 헤더, 서버 정보) |
| `response` | `HttpServletResponse` | 서버 응답 처리 (리다이렉트, 헤더 설정, 에러 전송) |
| `out` | `JspWriter` | HTML 스트림 출력 |
| `session` | `HttpSession` | 사용자 세션 관리 (13장에서 학습) |
| `application` | `ServletContext` | 웹 애플리케이션 전체 공유 데이터 |
| `config` | `ServletConfig` | Servlet 설정 정보 |
| `pageContext` | `PageContext` | 현재 페이지 컨텍스트 |
| `page` | `Object` | 현재 JSP 페이지 인스턴스 (this) |
| `exception` | `Throwable` | 에러 페이지에서만 사용 |

### 파라미터 처리 패턴 요약

| 상황 | 사용 메서드 | 반환 타입 |
|------|------------|-----------|
| 단일 값 입력 (text, radio, select) | `getParameter("name")` | `String` |
| 동일 name 다중 값 (checkbox) | `getParameterValues("name")` | `String[]` |
| 전체 파라미터 목록 순회 | `getParameterNames()` | `Enumeration<String>` |
| POST 한글 처리 | `setCharacterEncoding("utf-8")` | (최상단 호출) |

### 자주 쓰는 response 패턴

```jsp
<%-- 다른 JSP/URL로 이동 --%>
response.sendRedirect("대상.jsp");

<%-- 5초마다 자동 새로고침 --%>
response.setIntHeader("Refresh", 5);

<%-- HTTP 에러 응답 전송 --%>
response.sendError(404, "페이지 없음");
response.sendError(500, "서버 오류");
```

### Enumeration 순회 패턴

```jsp
<%@ page import="java.util.Enumeration" %>
<%
  Enumeration<String> e = request.getParameterNames(); // or getHeaderNames()
  while (e.hasMoreElements()) {
    String key = e.nextElement();
    String val = request.getParameter(key); // or getHeader(key)
    out.println(key + " = " + val + "<br/>");
  }
%>
```

### POST 한글 처리 주의사항

> **[중요]** `request.setCharacterEncoding("utf-8")`은 반드시 **`getParameter()` 호출 이전**, 처리 JSP 파일의 **최상단**에서 호출해야 한다.  
> 한 번이라도 `getParameter()`를 먼저 호출하면 인코딩 설정이 적용되지 않아 한글이 깨진다.

### sendRedirect 사용 시 주의사항

> **[경고]** `response.sendRedirect()` 호출 후에도 스크립틀릿의 나머지 코드는 계속 실행된다.  
> 리다이렉트 후 실행을 중단하려면 `return;`을 바로 다음에 추가해야 한다.

```jsp
<%
  if (조건) {
    response.sendRedirect("다른페이지.jsp");
    return; // ← 이 줄이 없으면 이후 코드도 실행됨
  }
%>
```
