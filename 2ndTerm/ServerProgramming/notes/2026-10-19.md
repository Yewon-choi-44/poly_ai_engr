**동작 원리:**
- **시큐리티(10장)**: `admin` 역할을 선언하고, `/2/loginForm.jsp`에 대한 GET 요청은 `admin` 역할 사용자만 접근하도록 제한. 인증은 FORM 방식으로 `/4/login.jsp`에서 받고 실패 시 `/4/login_failed.jsp`
- **필터(12장)**:
  - `<filter>`: 필터 이름(`logFilter`)과 구현 클래스(`com.filter.LoginYewonChoi`) 등록
  - `<filter-mapping>`: `/4/success.jsp` 요청이 들어오면 JSP보다 **먼저** 필터의 `doFilter()`가 실행됨

#### 📄 `src/main/java/com/filter/LoginYewonChoi.java` — 필터 클래스
```java
package com.filter;

import java.io.IOException;
import java.io.PrintWriter;

import javax.servlet.Filter;
import javax.servlet.FilterChain;
import javax.servlet.FilterConfig;
import javax.servlet.ServletException;
import javax.servlet.ServletRequest;
import javax.servlet.ServletResponse;

public class LoginYewonChoi implements Filter {
	@Override 
	public void init(FilterConfig filterConfig) throws ServletException {
		System.out.println("초기화");
	}
	
	@Override
	public void doFilter(ServletRequest request, ServletResponse response,
			FilterChain filterChain) throws IOException, ServletException {
		
		String name = request.getParameter("name");
		
		if (name==null || name.equals("")) {
			response.setCharacterEncoding("UTF-8");
			response.setContentType("text/html; charset=UTF-8");
			PrintWriter writer = response.getWriter();
			String message = "입력된 name 값은 null입니다.";
			writer.println(message);
			return;
		}
		filterChain.doFilter(request, response);
	}
	
	@Override
	public void destroy() {
		System.out.println("필터 해제");
	}
}
```
**동작 원리:**
- `javax.servlet.Filter` 인터페이스의 3개 메서드를 구현합니다 (교재 `ch12/com/filter/AuthenFilter.java`와 같은 구조).
  - `init()`: 웹 앱 시작 시 필터 객체가 만들어질 때 **한 번** 호출 → 콘솔에 "초기화"
  - `doFilter()`: 매핑된 URL로 요청이 올 때마다 호출
  - `destroy()`: 웹 앱 종료(또는 재배포) 시 **한 번** 호출 → 콘솔에 "필터 해제"
- `doFilter()` 흐름:
  1. `request.getParameter("name")`이 `null`이거나 빈 문자열이면
  2. 응답 인코딩·콘텐츠 타입을 UTF-8로 설정한 뒤 `response.getWriter()`로 안내 문구를 직접 출력하고 `return` → **요청이 JSP까지 가지 않고 필터에서 끝남**
  3. 값이 있으면 `filterChain.doFilter(request, response)`로 다음 필터 또는 원래 JSP로 요청을 넘김
- `response.setCharacterEncoding()`을 `getWriter()`보다 **먼저** 호출해야 한글이 깨지지 않습니다.

#### 📄 `loginForm.jsp` — 로그인 폼 + 비밀번호 길이 검사
```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>loginForm</title>
</head>

<script>
	
	function checkLogin( ){
		var form = document.loginForm;
		if (form.passwd.value.length > 12 || form.passwd.value.length < 8) {		
			alert("비밀번호는 영문자, 숫자 혼합 8자~12자까지 입력해야 합니다!");
			form.passwd.select();
			return;
		}	
	
		form.submit();
 } 
</script>

<body>
	<form method="post" action="loginForm_process.jsp" name="Member">
		<p> 아이디 : <input type "text" name="id">
		<p> 비밀번호 : <input type = "text" name="passwd">
		<p> <input type="submit" value="전송" onclick="checkLogin()">	
	</form>
</body>
</html>
```
**동작 원리 (의도):**
- 8장(JSP0918 `validation03.jsp`)의 **길이 검사** 패턴: `value.length`가 8~12자를 벗어나면 `alert` 후 `select()`로 입력값 전체 선택, `return`으로 제출 중단
- 통과하면 `form.submit()`으로 `loginForm_process.jsp`에 POST 제출
- 실제로는 폼 이름 불일치·버튼 타입 때문에 검증이 동작하지 않습니다(4번 이슈).

## 3. 핵심 JSP/Java 태그 및 문법

### 3-1. 필터(Filter) 생명주기

| 메서드 | 호출 시점 | 이 프로젝트에서 |
|---|---|---|
| `init(FilterConfig)` | 웹 앱 시작 시 1회 | "초기화" 콘솔 출력 |
| `doFilter(req, res, chain)` | 매핑된 요청마다 | `name` 파라미터 검사, 없으면 응답 직접 작성 후 종료 |
| `destroy()` | 웹 앱 종료 시 1회 | "필터 해제" 콘솔 출력 |

### 3-2. `FilterChain.doFilter()`의 의미

```
요청 ──▶ [Filter A] ──chain.doFilter()──▶ [Filter B] ──chain.doFilter()──▶ JSP/서블릿
                                                                              │
응답 ◀── [Filter A 후처리] ◀──────────── [Filter B 후처리] ◀──────────────────┘
```
- `chain.doFilter()`를 호출하지 않고 `return`하면 요청이 그 자리에서 끝나 JSP가 실행되지 않습니다 (인증·입력 검사 필터에서 사용하는 방식).

### 3-3. `web.xml` 설정 요소 정리

| 요소 | 역할 |
|---|---|
| `<filter>` / `<filter-name>` / `<filter-class>` | 필터 등록 (패키지 포함 전체 클래스명) |
| `<filter-mapping>` / `<url-pattern>` | 필터를 적용할 URL (`/*`이면 전체) |
| `<security-role>` | 사용할 역할 선언 |
| `<security-constraint>` | 보호할 URL과 허용 역할 |
| `<login-config>` | 인증 방식(FORM)과 로그인/오류 페이지 |

| `login_success.jsp` | 어디에서도 이 페이지로 이동하지 않음 | 연결 흐름 미완성 |

## 5. 💡 핵심 문법 정리 표 (Key Takeaways)

| 개념 | 설명 | 예시 |
|---|---|---|
| `Filter` 인터페이스 | `init` / `doFilter` / `destroy` 구현 | `public class X implements Filter` |
| `FilterChain.doFilter()` | 다음 필터 또는 대상 자원으로 요청 전달 | `filterChain.doFilter(request, response)` |
| 필터에서 요청 차단 | 응답을 직접 작성하고 `return` | `writer.println(message); return;` |
| 응답 한글 처리 | `getWriter()` 전에 인코딩 설정 | `response.setCharacterEncoding("UTF-8")` |
| `<filter>` / `<filter-mapping>` | 필터 등록과 URL 매핑 | `<url-pattern>/4/success.jsp</url-pattern>` |
| 역할 기반 접근 제한 | `security-constraint` + `auth-constraint` | `<role-name>admin</role-name>` |
| FORM 인증 예약어 | `j_security_check`, `j_username`, `j_password` | 교재 `ch10/login.jsp` |
| 클라이언트 길이 검사 | `value.length` 범위 비교 후 `select()` + `return` | `passwd.value.length < 8` |
| `type="button"` + `form.submit()` | 검증 통과 시에만 제출 | 8장 패턴 |
| `request.setCharacterEncoding()` | 파라미터 읽기 전에 호출 | `request.setCharacterEncoding("utf-8")` |
